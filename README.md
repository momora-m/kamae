# kamae

Windows 向けアクションゲームエンジン。実行ファイルはエディタを兼ねた `editor` ひとつです。

DirectX 11 と Dear ImGui（Docking）を使用し、ステージ編集からそのまま戦闘のプレイモードを開始できます。キャラクターの歩行、刃と銃を切り替える神機、近い捕食で弾を戻すこと、二種類の近接技の打ち合い、寿命を持つヒットボックス、個別ヒットストップ、自律して間合いを測る敵 AI を実装しています。

設計上の判断はすべて [Architecture Decision Records (docs/adr/)](docs/adr/README.md) に記録し、用語の定義は [kamae 用語集 (docs/words.md)](docs/words.md) に準拠しています。

## 主な機能

- **編集モードとプレイモードの分離**
  - 起動時は編集モードとして時間が停止しており、キャラクターの初期配置や敵の人数（最大 3 体）、床の広さを調整可能。
  - `Start` ボタンでプレイモードへ遷移し、その瞬間の配置を開始状態として記憶。
  - 戦闘停止後（プレイヤー敗北または敵全滅）は、停止理由を確認しつつ、ワンクリックで開始状態からやり直す（Play again）か、編集モードへ復帰（Return to start）できます。
- **シーン保存と読み込み**
  - アリーナの床サイズやキャラクター初期配置をテキスト形式の名前付きシーンとして保存・復元（`scenes/` 配下）。
  - いつでも安全な規定の 1 対 1 初期配置へリセット可能。
- **戦闘とゲームループ**
  - **二種類の技**: 前方 1.0・間隔 0.4 秒の短い技（Space）と、前方 2.0・間隔 1.0 秒の長い技（F）。
  - **神機**: `R` で刃と銃を切り替える。刃は短い技と長い技。銃は `G`、弾を 1 消費し、前方 4.0・間隔 0.5 秒。開始時の弾は 3。0 では出ない。相手は刃のまま。
  - **捕食**: `C`。刃でも銃でも出せる。前方 0.6・間隔 0.6 秒。相手に重なったときだけ弾が 1 戻り、3 を超えない。空振りでは戻らない。相手は食わない。
  - **先行入力**: クールダウン終了前 0.15 秒以内の入力を 1 回分バッファリング。
  - **ヒットボックス**: 攻撃発生から 3 フレーム持続し、判定と同一形状で描画（多重ヒット防止）。
  - **個別ヒットストップ**: 被弾したキャラクターのみ 4 フレーム間更新時間（Delta Time）を 0 秒化。
  - **軸別衝突解消**: 壁およびキャラクター同士の移動衝突を軸ごとに判定・取り消し（スライド移動）。
- **敵 AI**
  - プレイヤーへ接近しつつ、正面軸から外れるように横へ旋回。
  - 間合いに応じた技の選択（短い技が届かないときは長い技）。相手は銃を持たない。
  - 攻撃後は間合いの外へ後退して仕切り直し。

## 画面構成と操作

| パネル / メニュー | 内容と操作 |
| --- | --- |
| **Scene** | 画面上部メニュー。編集中のみ有効。シーン名の指定、保存（Save scene）、保存済み一覧からの読み込み、初期配置へのリセット（Reset to initial）。 |
| **Viewport** | 3D レンダリング画面。床、外壁、キャラクターのメッシュ、各キャラクターの体力バー、攻撃ヒットボックスを表示。プレイヤーと相手は同じメッシュで、色だけが違う。<br>・**カメラ操作**: 編集中は左ドラッグでプレイヤー中心に回転し、離しても残る。プレイ中は追従の基準の背中へ付き、移動キーを離してもその位置に残る。左ドラッグで動かしたヨーとピッチは、離しても残る。残った水平ヨーが、そのあとの移動の基準になる。停止中は体の背中へ付き、左ドラッグで動かしたヨーとピッチも離しても残る。<br>・**移動**: プレイ中、ビューポートにカーソルがある状態で `W` `A` `S` `D`。前後左右は、そのときのカメラの水平方向。移動中だけ体がその方向を向く。`W` は視線の奥、`A` は左、`D` は右、`S` は手前で顔がカメラを向く。キーを離すとヨーは残り、カメラは押していたあいだの位置に残る。<br>・**攻撃**: 刃では `Space` で短い技、`F` で長い技。`R` で銃に切り替えると `G` で撃つ。弾は 3 から減り、0 では出ない。`C` で捕食する。刃でも銃でも出せる。前方 0.6。重なったときだけ弾が 1 戻り、3 を超えない。空振りでは戻らない。<br>・**ジャンプ**: 床にいるとき `Q`。空中では跳べない。<br>・**回避**: 床にいるとき `E`。6 フレーム、ヒットを受けない。 |
| **Subjects** | 各キャラクターの管理パネル。<br>・**編集中**: 座標やヨー角の変更、敵キャラクターの追加・削除（最大 4 体）、床の半辺調整、`Start` ボタン。<br>・**停止中**: 停止理由（勝敗）の通知、`Play again`（再戦）、`Return to start`（編集へ復帰）。 |
| **Camera** | プレイヤーからのカメラ距離の調整。プレイ中のカメラは追従の基準の背中に付き、このパネルからは距離だけを変える。 |
| **Render** | 背景クリア色の設定。 |

## 開発環境とビルド

### 必要な環境

- **OS**: Windows 10 以降
- **IDE / ツール**: Visual Studio 2022（「C++ によるデスクトップ開発」ワークロード）
- **SDK**: Windows 10 SDK
- **ビルドツール**: CMake 3.24 以上
- **その他**: Git（CMake の `FetchContent` で Dear ImGui `v1.92.9b-docking` を取得）

### ビルド手順

Visual Studio 2022 の Developer PowerShell または **x64 Native Tools Command Prompt** でリポジトリルートを開きます。

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

※ `build/editor.sln` を Visual Studio 2022 で開き、スタートアッププロジェクトを `editor` に指定してビルド・実行することも可能です。

### 実行

```bat
.\build\Release\editor.exe
```

- シェーダ（`shaders/lit.hlsl`）はビルド時に実行ファイルの隣へコピーされ、起動時に `D3DCompile` でコンパイルされます。
- キャラクターのメッシュ（`assets/character.gltf` と `assets/character.bin`）も、ビルド時に実行ファイルの隣へコピーされます。起動時にその隣の `character.gltf` を読みます。
- シーンデータは実行ファイルと同じ作業ディレクトリの `scenes/` フォルダへ入出力されます。
