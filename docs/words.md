# ことば

文書で使う、ゲーム開発で普通の言葉。意味は一つ。コードの型名は英語のまま。

## キャラクター

プレイヤーと相手。並びで持つ。コードでは `Subject`。

## 編集モード / プレイモード

起動は編集モード。時間は止まる。Start でプレイモード。歩きと攻撃はプレイモードだけ。止めたあとは自動では再開しない。コードでは `SessionMode`（`Editing` / `Trial` / `Stopped`）。

## ヒットボックス

攻撃の判定に使う直方体。描画も同じもの。コードでは `AttackMark`。

## ヒット

ヒットボックスが他のキャラクターに重なった結果。コードでは `Hit`。歩きながらの接触はヒットではない。

## 入力

今フレームの、水平の歩きと、攻撃する／しない。コードでは `SubjectActions`。キーそのものではない。画面のボタンは入力と呼ばない。

## コントローラー

キャラクターに付き、入力を出す。最初はプレイヤーのキーと相手の接近。コードでは `Controller`。着脱する画面は無い。

## デルタタイム

そのフレーム、そのキャラクターの歩きと攻撃に渡す秒。全体の倍率ではない。文書では Δt とも書く。

## 残り

体力。3 から始まり、ヒットで 1 減る。0 のキャラクターは描かない。コードでは `remaining`。

## ヨー

水平の向き。ピッチは上下、ロールは傾き。

## 開始状態

Start を押したときの配置。戦闘の途中は含まない。コードでは `StartLayout`。

以前の文書で「試走」はプレイモード、「主体」はキャラクター、「箱」はヒットボックス、「当たり」はヒット、歩きと攻撃の意味の「操作」は入力。
