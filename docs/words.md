# kamae 用語集

kamae の設計文書（ADR）およびコードで共通して使用する用語の定義。日常的なゲーム開発用語に対応させており、独自の方言は設けない。

## キャラクター（Character）
ゲーム空間内に存在するプレイヤーや敵の立方体オブジェクト。現在は固定長配列で管理される。コード上の型名は `Subject`。

## 編集モード / プレイモード（Editing Mode / Play Mode）
- **編集モード**: 起動時の初期状態。時間は停止しており、パネルからキャラクターの位置やヨー角、敵の人数、ステージの広さを編集できる。
- **プレイモード**: `Start` ボタン押下で開始する動作確認・戦闘実行状態。キャラクターの移動や攻撃が動作する。全滅等で停止した後は、開始時の配置（開始状態）へ戻す操作で編集モードへ復帰する。コード上の型名は `SessionMode`。

## プレイセッション（Play Session）
プレイモード中のゲームループ全体の実行管理。キャラクター配列の更新、入力の伝達、ヒットボックスの生成・寿命管理、ヒット判定の適用などを司る。コード上は主に `trial.cpp` および `SceneState` が担う。

## 入力（Actions / Input）
コントローラーから各キャラクターへ毎フレーム伝達される移動・攻撃の要求データ。水平移動ベクトルと攻撃トリガーフラグで構成される。キーボードやマウスの生イベントそのものではなく、抽象化されたアクションを表す。コード上の型名は `SubjectActions`。

## コントローラー（Controller）
各キャラクターに紐づき、毎フレームの入力を生成する処理単位。プレイヤー用（キー入力読み取り）と敵用（接近・間合い判定による自律入力）が存在する。コード上の型名は `Controller`。

## ヒットボックス（Hitbox / 攻撃判定）
攻撃時に生成される直方体の当たり判定。見た目の描画と実際の判定で同一の形状を共有する。コード上の型名は `AttackMark`。

## ヒット（Hit）
ヒットボックスが相手キャラクターと交差・接触した判定結果。プレイセッションがこの結果を受け取り、体力の減少やヒットストップを適用する。移動時のキャラクター同士の押し合い・接触はヒットではない。コード上の型名は `Hit`。

## 体力（HP / Remaining）
キャラクターの耐久値。初期値は 3 で、攻撃がヒットするごとに 1 減少する。0 になったキャラクターは死亡扱いとなり、描画・判定・移動障害から除外される。コード上のフィールド名は `remaining`。

## フレーム更新時間（Delta Time）
各キャラクターの移動やクールダウン処理に渡される 1 フレームあたりの経過時間（秒）。被弾したキャラクターには一時的に 0 秒を渡すことで、個別ヒットストップを実現する。

## ヨー角（Yaw）
キャラクターやカメラの水平方向の向き（Y 軸周りの回転角）。

## 開始状態（Start Layout）
プレイモード開始（Start 押下）時点のステージおよびキャラクターの配置。プレイ終了後に編集モードへ戻る際の復元先となる。コード上の型名は `StartLayout`。
