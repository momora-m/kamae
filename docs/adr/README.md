# Architecture Decision Records

後から覆しにくい設計判断を簡潔に残す記録。実装の具体的な手順や UI の操作説明、日々の軽微な不具合修正はここには含めない。

使用する共通語彙は [kamae 用語集](../words.md) を参照。各 ADR は「ひとつの判断」「採用した理由」「あえて採用しなかったもの（スコープ外）」に集中して記述し、前後の ADR の内容を過剰に再掲しない。

## ファイル名

`NNNN-kebab-title.md`

- `NNNN`: 4 桁の連番。`0001` から開始し、再利用しない。
- `kebab-title`: 判断内容を示す短い英語タイトル（ハイフン区切り）。

例: `0001-dx11-imgui-editor-slice.md`

## ステータス

各 ADR の先頭に以下のいずれかを明記する。

| ステータス | 意味 |
| --- | --- |
| `proposed` | 提案中（未採用） |
| `accepted` | 採用済み（現在の実装の前提） |
| `superseded` | 後続の ADR によって置き換えられた（後継文書へのリンクを記載） |

後続の判断によって決定の一部が更新された場合でも過去の文書は削除せず、`accepted` のまま変更点を明記するか、全体が置き換わった場合は `superseded` とする。
