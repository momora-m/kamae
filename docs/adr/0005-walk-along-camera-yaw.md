# カメラの水平ヨーでも歩けるようにする

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

三人称アクションゲームでは、キャラクター自身の向きではなくカメラが見ている水平方向を基準として WASD 移動を行う操作系が一般的である。既定のキャラクター基準移動を保ちつつ、カメラ基準移動への切り替えを可能にする。

## 決めたこと

- 既定の移動動作は [0004](0004-cube-walks-its-facing.md) のキャラクター基準を維持する。
- Camera パネルに切り替えトグル（`walk_with_camera_yaw`）を追加する。
- カメラ基準が有効な場合：
  - W キーでカメラの水平ヨー角方向（ピッチ角は無視）へ前進する。
  - 移動中のフレームのみ、キャラクターのヨー角を移動方向へ向ける。移動停止時はその向きを保持する。
- フラグが無効な場合は、[0004](0004-cube-walks-its-facing.md) どおりキャラクター自身のヨー角で移動し、歩行によってヨー角を上書きしない。

## 採らないこと

カメラのロール角や仰角を移動ベクトルに混入させること、コントローラー抽象化、キーコンフィグ。
