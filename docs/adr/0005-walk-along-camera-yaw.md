# カメラの水平ヨーでも歩けるようにする

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

三人称では、地面の前後はカメラのヨーを水平に落とした向きであることが多い。仰角は進行に混ぜない。その歩き方を、自分のヨーで歩く隣に置く。

## 決めたこと

既定は [0004](0004-cube-walks-its-facing.md) のままである。Camera パネルの切り替え一つで、進行方向をカメラのヨーにする。

切り替えたとき、W はそのヨーを XZ へ落とした向き、S は逆、D はその右、A は左。ピッチは無視する。斜め入力は速さを増やさない。動いているフレームだけ、ヨーを移動方向へ向ける。止まっているときはヨーを保つ。A と D だけでその場回転はしない。

切り替えていないときは、進行方向は立方体のヨーであり、歩行はヨーを上書きしない。

切り替えは `SceneState` の一つの値である。既定はオフである。

## 採らない

ロールを進行に混ぜること。入力の抽象化。コントローラーを付ける画面。
