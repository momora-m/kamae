# カメラの水平ヨーでも歩けるようにする

- 状態: `accepted`
- 日付: 2026-09-24
- 追加: 歩く主体と、カメラが見る位置はプレイヤーである。[0007](0007-player-and-opponent-one-loop.md)。切り替えの規則はここが現在の決定である。

## 文脈

[0004](0004-cube-walks-its-facing.md) では、WASD は立方体のヨーだけを見る。カメラを回しても進行方向は変わらない。歩行はヨーを上書きしない。

一般的な三人称では、地面の上の前後はカメラのヨーを水平に落とした向きである。仰角は進行に混ぜない。ロールは使わない。その歩き方も、立方体のヨーで歩く隣に置く。

## 決定

既定は 0004 のままである。Camera パネルの切り替え一つで、進行方向をカメラのヨーにする。

切り替えたとき、W はそのヨーを XZ 平面へ落とした向き、S は逆、D はその右、A は左である。ピッチは無視する。斜め入力は正規化し、速さは増やさない。動いているフレームだけ、ヨーを移動方向へ向ける。止まっているときはヨーを保つ。A と D だけでその場回転はさせない。

切り替えていないときは、進行方向は立方体のヨーであり、歩行はヨーを上書きしない。

速さは秒あたり 2.5、経過時間の上限は 0.1 秒、Y は変えない、のままである。カメラは今の球面のまま、立方体の位置を見続ける。

当たり判定、アニメーション、二体目のメッシュ、入力の抽象化、コンポーネントの一覧、コントローラーを付ける画面、ロールは含めない。

## 結果

- 切り替えは `SceneState` の一つの値である。既定はオフである。
- オフのときの位置と回転は、0004 のままである。
- オンのとき、歩いているフレームのヨーは移動方向である。パネルのピッチとロールはそのままである。
