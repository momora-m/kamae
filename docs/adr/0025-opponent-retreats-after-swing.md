# 相手は撃ったあと、間合いの外まで下がる

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [相手は撃ったあと、間合いの外まで下がる](https://github.com/momora-m/kamae/issues/85)

## なぜ

相手は間合いに入ると、その場に残って 0.8 秒ごとに撃ち続けた。プレイヤーが後ろへ下がっても、相手は間合いを保ったまま次の攻撃を出せた。撃ったあとに一度下がれば、次の攻撃の前に歩き直す間ができる。

## 決めたこと

相手が攻撃を出したフレームの次から、今の攻撃のヒットボックスがプレイヤーに重ならなくなるまで、プレイヤーから離れる向きに歩く。下がっているあいだは攻撃しない。向きはプレイヤーの方を向いたまま、水平の歩きを後ろにする。新しい状態名は増やさない。`Attack` も増やさない。

重なりが消えたフレームから、また近づく。次の初撃は、ヒットボックスが再び重なってから 0.5 秒待つ。待ちの途中で重なりが消えれば、待ちは捨て、次に重なったときまた 0.5 秒待つ。居続けて 0.8 秒ごとに撃つ繰り返しは、この後退に置き換える。

攻撃を出せるのは、その待ちが終わり、クールダウンも 0 のフレームである。出したフレームは立ち止まって撃つ。プレイヤーの間隔 0.4 秒と、終わり 0.15 秒の先行入力は変えない。相手がこの一撃で覚えるクールダウンも 0.4 秒である。0.5 秒の再進入の待ちより短いので、次の初撃を遅らせない。

## 採らないこと

回り込み、複数の技、溜め、無敵、アニメーション、経路探索。壁に阻まれて下がりきれないときは、重なりが消えるまで後退を続ける。別の経路は探さない。
