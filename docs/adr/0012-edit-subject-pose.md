# パネルで位置とヨーを編集する

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

GUI から配置を置く第一歩として、プレイヤー以外のキャラクターも、パネルで位置とヨーを変えられるようにする。保存はまだしない。

## 決めたこと

パネルはキャラクターの並びを出す。各キャラクターの位置を編集する。先頭のピッチ、ヨー、ロールは、今の三つの回転スライダのまま。それ以外にはヨーだけを出す。先頭はプレイヤーのまま。パネルから役割は変えない。色、体力、人数は変えない。

編集した値は、そのキャラクターの位置とヨーそのものである。別の編集用コピーは持たない。ファイルには書かない。再起動すると、コードに書いた初期配置に戻る。

パネルは、そのフレームの歩行と攻撃の前に書く。書いた位置は、そのフレームの歩行、攻撃、カメラに効く。

相手のヨーをドラッグしているフレームは、接近がそのヨーを置き換えない。歩行はする。攻撃のヒットボックスは、そのヨーの前方である。ドラッグを離すと、次のフレームから接近が移動方向かプレイヤー方向へヨーを向ける。

このパネルは `main.cpp` とは別のファイルに置く。

## 採らない

人数の増減。床の大きさ。保存と読み込み。相手の種類。色の編集。`Character` 基底。

## あとから

[0015](0015-edit-then-start-a-trial.md) は、プレイ中に配置を編集する操作を出さないと決めた。ヨーをドラッグしている相手は接近がヨーを置き換えない、という判断はここから消していない。プレイ中はスライダが無いので、二つの判断は同時には起きない。どちらもひっくり返していない。
