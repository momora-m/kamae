# パネルで位置とヨーを編集する

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

敵キャラクターの初期配置や向きをソースコードの直接編集（リビルド）ではなく、エディタの GUI パネルからインタラクティブに配置・調整できるようにする。

## 決めたこと

ImGui の Subjects パネルに全キャラクターの姿勢編集 UI を追加する。
- 全キャラクターの X, Y, Z 位置スライダを提供する。
- 先頭キャラクター（プレイヤー）にはピッチ・ヨー・ロールの 3 軸回転スライダを提供し、それ以外の敵キャラクターには水平向きであるヨー角のみを提供する。
- パネルで編集した値は、キャラクターの実際の座標データそのものを直接更新する（別の編集専用バッファは持たない）。
- パネル処理はフレーム内の移動・攻撃処理の前に実行し、変更結果がそのフレームの挙動に即座に反映されるようにする。
- **ヨー角ドラッグ中の特例**: ユーザーがパネルで敵のヨー角スライダーをマウスドラッグしているフレームに限り、敵の接近処理によるヨー角の自動上書きを抑制する（ドラッグによる姿勢確認を優先する）。ドラッグ解除後は再び接近方向を向く。

## 採らないこと

キャラクター人数の動的増減（[0013](0013-add-remove-opponents.md) で決定）、ステージサイズ変更、ファイルへの保存・読み込み機能。

## 後続との関係

後続の [0015](0015-edit-then-start-a-trial.md) により、プレイモード中は配置編集 UI 自体を非表示にする決定が下された。したがって「ヨー角ドラッグ中の上書き抑制」は現在、編集モードとプレイモードが分離されたことでプレイ中に発生しなくなっているが、ロジック自体は矛盾なく共存している。
