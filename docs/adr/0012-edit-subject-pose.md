# パネルで全主体の位置とヨーを編集する

- 状態: `accepted`
- 日付: 2026-09-24

## 文脈

[0007](0007-player-and-opponent-one-loop.md) で、パネルが編集するのはプレイヤーの位置と回転だけである。相手の初期位置は `(0, 0, 4)`、ヨーは 180 度で、コードに書いてある。カメラはプレイヤーを見る。

[0011](0011-opponent-same-attack.md) で、相手はプレイヤーの XZ へ歩き、移動したフレームのヨーはその方向を向く。攻撃の範囲ではプレイヤーの方を向く。

GUI からゲームを置く第一歩として、プレイヤー以外の主体も、パネルで位置とヨーを変えられるようにする。保存はまだしない。

## 決定

パネルは主体の並びを出す。各主体の位置を編集する。先頭のピッチ、ヨー、ロールは、今の三つの回転スライダのままである。それ以外の主体にはヨーだけを出す。先頭はプレイヤーのままである。パネルから役割は変えない。色、残り、人数は変えない。

編集した値は、その主体の位置とヨーそのものである。別の編集用コピーは持たない。ファイルには書かない。再起動すると、コードに書いた初期配置に戻る。

パネルは、そのフレームの歩行と攻撃の前に書く。書いた位置は、そのフレームの歩行、攻撃、カメラに効く。

相手のヨーをドラッグしているフレームは、接近がそのヨーを置き換えない。歩行はする。攻撃の箱は、そのヨーの前方である。ドラッグを離すと、次のフレームから接近が移動方向かプレイヤー方向へヨーを向ける。ドラッグしていない主体のヨーは、0011 のままである。

このパネルは別の翻訳単位に置く。`main.cpp` はウィンドウ手続きと、パネル、歩行、解消、攻撃、描画の呼び出しのままである。主体は並びのままである。`Character` 基底や Player / Opponent 型は作らない。

主体の増減、床の大きさ、保存と読み込み、相手の種類、色の編集は含めない。

## 結果

- 相手の位置を変えると、立方体はその場所から歩く。ヨーをドラッグすると、その向きのまま立方体が動く。
- プレイヤーの歩行とカメラは、今までどおりである。
- 再起動すると、コードに書いた初期配置に戻る。
