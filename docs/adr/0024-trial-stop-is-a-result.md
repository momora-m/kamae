# プレイの停止理由を、プレイセッションが返す結果にする

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [プレイの停止理由を、プレイセッションが返す結果にする](https://github.com/momora-m/kamae/issues/84)

## なぜ

プレイセッションは、止まるかどうかだけを返していた。プレイヤーの体力が尽きたときと、使っている相手が全員尽きたときは、同じ停止になる。止まった画面を見ても、どちらで止まったかが分からない。

## 決めたこと

プレイセッションが返す停止の結果は、次の三つである。

- 続行
- プレイヤーの体力が尽きた
- 使っている相手が全員尽きた

止まる条件は変えない。プレイヤーの体力が 0 なら、相手が残っていても「プレイヤーの体力が尽きた」を返す。相手が 0 人のときは、相手側の結果は出さない。使っている相手が 1 人以上いて、その全員の体力が 0 のときだけ「使っている相手が全員尽きた」を返す。同じフレームで両方尽きたときは、プレイヤーの結果を返す。

停止中、Subjects パネルはその一文だけを出す。プレイ中と編集中には出さない。自動では再開しない。Return to start は開始状態へ戻して編集モードに入る。

## 採らないこと

リザルト画面、スコア、ラウンド、コンティニュー、効果音。停止の一文は、既存の Subjects パネルに出す。勝敗の演出画面は作らない。

## 後続の更新

停止中に同じ開始状態からプレイを始め直す操作は、[0028](0028-restart-trial-from-start.md) で入った。Return to start が編集モードに戻すことは変わらない。
