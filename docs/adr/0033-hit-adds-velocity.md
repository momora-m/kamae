# 当たると攻撃の前方へ速度を足す

- 状態: `accepted`
- 日付: 2026-09-27
- 言葉: [../words.md](../words.md)
- 作業: [当たると攻撃の後方へ少し押し出される](https://github.com/momora-m/kamae/issues/99)

## なぜ

ヒットは体力を減らし、当たったキャラクターのフレーム更新時間を止めるだけだった。位置も速度も変わらないため、当たったあとも同じ間合いで打ち返せる。位置を一度ずらすと、次のフレームへ残る弾みがなく、[0032](0032-velocity-falls-to-floor.md) の速度と二重の移動手段になる。当たった力は、その速度へ足す。

## 決めたこと

プレイセッションがヒットを適用するとき、体力とヒットストップに加えて、当たったキャラクターの水平速度へ、そのヒットボックスの前方へ向かう速さを足す。位置を一度ずらすことはしない。

- **向きと大きさ**:
  - 前方は、ヒットボックスを出したときの攻撃者のヨーの前向きである。ヒットボックスがその向きを覚える。
  - 足す速さは 1.0 とする。歩行 2.5 より小さく、短い技の間隔 0.4 秒のあいだ歩きで置き換わらなければ、立方体の半辺 0.5 に届かない 0.4 だけ間合いが開く。今の打ち合いに合う最小に近い値である。
- **適用**:
  - 防いだヒットは速度を足さない。体力もヒットストップも置かない判断は [0031](0031-guard-blocks-frontal-hit.md) のままである。
  - 速度を足したあと、そのフレームの位置へフレーム更新時間を掛けて足す。歩きによる置き換えは、その前に済ませておく。
  - ヒットストップ中はフレーム更新時間が 0 なので、位置は進まない。明けたあと、歩きが水平速度を置き換えれば、当たった力は消える。
- **開始と保存**:
  - 開始状態とシーンは、今どおり位置、ヨー、色、床の半辺だけを覚える。速度は書かない。

## 採らないこと

位置を一度ずらすこと、物理ライブラリ、打ち上げ、壁への叩きつけ、コンボ、アニメーション、摩擦、技ごとの速さの差。
