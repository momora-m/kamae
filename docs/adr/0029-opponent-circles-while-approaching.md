# 相手は近づく途中で横に回る

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [相手は近づく途中で横に回る](https://github.com/momora-m/kamae/issues/89)

## なぜ

敵キャラクターがプレイヤーの座標へ向かって直線的に最短距離で接近していたため、プレイヤーの正面正面の攻撃線上に飛び込みやすく、単調な接近戦になっていた。攻撃間合いに入る前の接近移動中に横方向のスライド移動を加えることで、正面攻撃を避けつつ側面へ回り込む初歩的なポジショニングを実現する。

## 決めたこと

敵コントローラーが生成する接近中の水平移動ベクトルに、プレイヤーの正面軸を外す横移動成分（ストラフ）を付与する。

- **横移動の判定条件**:
  - プレイヤーの水平ヨー角に基づく右方向軸に対して、敵キャラクターの中心座標のオフセットを計算する。
  - オフセットの絶対値が 1.0（キャラクター立方体の半辺 0.5 ＋ 弱攻撃判定の左右幅 0.5）未満の場合は、中心軸からのズレをさらに広げる方向へ横移動入力を加える（完全に正面（0.0）の場合はプレイヤーの右側へ回避）。
  - オフセットが 1.0 以上の場合は正面の攻撃線を外れているとみなし、横移動成分を 0 としてプレイヤーへ直進する。
- **他状態との整合性**:
  - 横移動を行うのは「接近（Approach）」状態のフレームのみとする。攻撃間合いに入った後の「間合い待ち（Wait）」、「攻撃（Fire）」、および攻撃後の「後退（Retreat）」の処理は一切変更しない。
  - 移動ベクトルの変更のみで実現し、敵専用の新しいステートマシン状態や独立した移動ルーチンは新設しない。
- **マイルストーンにおける位置づけ**:
  - 本機能は二技の打ち合い成立後の拡張であり、プレイモードの基本成立（MVP フェーズ）を完了するための必須要件には含めない。

## 採らないこと

プレイヤー側のステップ回避アクション、動的な経路探索、障害物や壁の事前回避ルーチン。
