# 相手は近づく途中で横に回る

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [相手は近づく途中で横に回る](https://github.com/momora-m/kamae/issues/89)

## なぜ

相手の接近は、プレイヤーの XZ へまっすぐ歩く。正面に立ったまま入ると、短い技の線上に乗りやすい。近づく途中だけ、プレイヤーの正面から外れる向きに横へ歩く。

## 決めたこと

近づいているあいだだけ、相手の水平の歩きに横成分を足す。プレイヤーの右方向へのずれが 1.0 未満のとき、そのずれが大きくなる側へ歩く。ずれが 0 のときは、プレイヤーの右へ歩く。1.0 は、立方体の半辺 0.5 と短い技の左右 0.5 を足した幅である。ずれが 1.0 以上なら、横成分は 0 で、まっすぐ近づく。

間合いに入ったあとの待ち、撃ち、後退は変えない。新しい状態は増やさない。`Attack` も増やさない。この判断は、二つの技で打ち合えるようになったあとの追加である。段階を終える条件には入れない。

## 採らないこと

プレイヤーの回避、技の追加、経路探索。横歩きは近づくあいだだけで、間合いの中では立ち止まって待つ。
