# プレイ中、カメラは背中に付き、移動はその前後左右になる

- 状態: `accepted`
- 日付: 2026-09-30
- 言葉: [../words.md](../words.md)
- 作業: [プレイ中、カメラは背中に付き、移動はその前後左右になる](https://github.com/momora-m/kamae/issues/108)

## なぜ

編集中のカメラは、左ドラッグでプレイヤーの周りを回り、ボタンを離してもその位置に残る。プレイ中の移動は、切り替えが無いときはプレイヤーのヨーが基準で、歩行はそのヨーを変えない。見た目がメッシュになって前後が分かれたので、プレイ中は背中側から見て、移動をそのカメラの前後左右に揃えないと、体の前と進行がずれる。

移動入力があるあいだ追従の基準を固定したうえで、入力が無いフレームでは体のヨーをその基準へ戻していた。S はカメラの手前へ歩き、体はカメラを正面に見る。その向きを離したフレームで追従へ戻すと、カメラが半回転する。Windows での確認で、その半回転が気になる、と分かった。

プレイ中と停止中の左ドラッグは、ボタンを押しているあいだだけ周りを見て、離したフレームでヨーとピッチのずれを 0 に戻していた。カメラは、プレイ中なら残っている追従の基準の背中へ、停止中ならプレイヤーの体のヨーの背中へ戻る。Windows での確認で、クリックを離すとカメラの位置が戻るのが気になる、と分かった。動かしたヨーとピッチは離したあとも残し、残った水平ヨーを、そのあとの移動の基準にする。

## 決めたこと

プレイ中、描画するカメラは追従の基準の背中側に、左ドラッグで残したずれを足して置く。その基準は、移動キーを離しても体のヨーへコピーしない。停止中は、プレイヤーの体のヨーの背中側に、同じずれを足して置く。左ドラッグで動かしたヨーとピッチは、ボタンを離しても戻さない。編集中のドラッグも、離してもそのヨーとピッチに残す。

- **背中**:
  - プレイヤーのヨー 0 は +Z を向く。カメラは、その逆側からプレイヤーを見る。水平のカメラヨーは、向いている基準に 180 度を足し、さらに残っているヨーのずれを足した角である。
  - プレイ中の追従の基準は、プレイの開始とやり直しで、開始配置のプレイヤーのヨーから置く。移動入力があるあいだは、その移動が書いたヨーへ基準を移さない。移すと、次のフレームの左右と手前が別の水平ヨーになり、体のヨーが回り続ける。キーを離したフレームでも、基準を体のヨーへコピーしない。カメラは、押していたあいだの位置に残る。体のヨーだけが残る。
  - ピッチと距離は、編集中に残した値を使う。プレイ中と停止中の左ドラッグが足したピッチのずれは、ボタンを離しても残す。ピッチは移動方向に入れない。
  - 注視点は、今どおり先頭のキャラクターである。相手の移動は、このカメラを基準にしない。
- **ドラッグ**:
  - プレイ中と停止中、ビューポート上の左ドラッグは、ヨーとピッチのずれを足して周りを見る。ボタンを離したフレームでも、そのずれは 0 に戻さない。カメラは、離したときのヨーとピッチに残る。
  - 残った水平のずれは、そのフレームに描画するカメラの水平ヨーに入る。その水平ヨーが、そのあとの移動の基準になる。W は、残った視線の奥へ進む。
  - 停止中の基準は、プレイヤーの体のヨーのままである。キーを離したときに追従の基準をコピーしない規則は、停止中には当てない。残るのは、ドラッグのずれである。
  - 編集中は、今どおり左ドラッグがヨーとピッチを変え、離しても残る。プレイの追従は、この編集中の角を上書きしない。編集へ戻ったフレームから、その角を再び使う。
- **移動**:
  - プレイ中のプレイヤーの前後左右は、そのフレームに描画しているカメラの水平ヨーである。左ドラッグで残した水平のずれも、この水平ヨーに入る。
  - W はカメラの水平視線の方向（奥）へ歩き、体のヨーもその方向を向く。
  - A はカメラの左へ歩き、体のヨーもその左を向く。D はカメラの右へ歩き、体のヨーもその右を向く。
  - S はカメラの位置の方（手前）へ歩き、体のヨーはカメラを正面に見る向きになる。
  - 斜め入力も、そのフレームの移動方向を体のヨーにする。
  - 移動入力が無いフレームは、体のヨーを上書きしない。追従の基準も、このフレームでは体のヨーへ移さない。次に押した W は、残っている同じカメラの奥へ進む。A、D、S も、その同じ水平ヨーである。
  - 技の前は、その体のヨーの前方である。ヒットボックスの前方も、同じヨーを使う。
  - 床の上の歩きが水平速度を置き換えること、空中で歩けないこと、壁と他のキャラクターに重なった軸を戻すことは、変えない。
  - 相手の接近は、このカメラを基準にしない。
- **切り替え**:
  - カメラ基準とキャラクター基準を切り替える操作は外す。プレイ中の移動は、常にカメラの水平ヨーである。

## 採らないこと

ジャンプ、回避、歩くアニメーション、銃、捕食、ロックオンは入れない。カメラを遅れて追従させること、編集中に背中へ付けること、相手をこのカメラで歩かせることも採らない。キーを離したあとに追従の基準を体のヨーへコピーすること、停止中の基準を体のヨーから追従の基準へ変えること、開始とやり直しで追従の基準を開始配置のヨー以外から置くことも採らない。

## 後続の更新

動作確認で、移動が書いたヨーを同じカメラの追従へ戻すと、A、S、D のヨーが毎フレーム別の値になった。W は視線の方向と体のヨーが一致するため、そのままでも前へ進んで見えた。追従の基準は、移動入力があるあいだ固定する。

その固定のあと、入力が無いフレームで基準を体のヨーへ戻していた。S を離すと体がカメラを向いたままなので、カメラが半回転した。キーを離したフレームでは基準をコピーしない。停止中は、体のヨーの背中へ付く。

そのあと、左ボタンを離すとヨーとピッチのずれが 0 に戻り、カメラが追従の基準、または停止中は体のヨーの背中へ戻っていた。Windows での確認で、この戻りが気になる、と分かった。プレイ中と停止中とも、離したあとそのずれを残す。残った水平ヨーを、そのあとの移動の基準にする。編集中にドラッグが残ること、移動キーを離しても追従の基準を体のヨーへコピーしないこと、開始とやり直しで追従の基準を開始配置のプレイヤーのヨーから置くことは、変えない。
