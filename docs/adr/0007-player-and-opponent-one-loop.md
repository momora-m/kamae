# プレイヤーと相手を同じループに置く

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

立方体が一つだった。プレイヤー用と相手用にフィールドを分けると、三人目でまたフィールドが増える。エンティティとコンポーネントで分ける段階ではない。

## 決めたこと

キャラクターは並びで持つ。先頭がプレイヤー、次が相手。三人目は要素を足す。`SceneState` にキャラクターごとの専用フィールドは足さない。

各キャラクターは位置とヨーを持つ。ピッチとロールは、パネルが編集している回転の残りとして、そのキャラクターに残す。プレイヤーの初期位置は原点、ヨー 0。相手の初期位置は `(0, 0, 4)`。ヨー 0 は +Z を向くので、相手のヨーは 180 度とし、プレイヤーのいる -Z を向く。相手のピッチとロールは 0。

見た目は今の立方体のまま、同じ頂点を描く。色だけキャラクターごとに分ける。面ごとの色は付けない。プレイヤーは `(0.78, 0.48, 0.27)`。相手は `(0.25, 0.42, 0.68)`。

WASD はプレイヤーだけを動かす。カメラはプレイヤーを見る。パネルが編集するのは、当時はプレイヤーの位置と回転だけである。この記録では相手は動かない。

## 採らない

攻撃。相手の移動。壁。重力。落下。物理ライブラリ。アニメーション。種類ごとのメッシュ。`Character` 基底や Player / Opponent 型。
