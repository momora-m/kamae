# プレイヤーと相手を同じループに置く

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

単一の立方体のみを扱う状態から、対戦相手となる 2 体目のキャラクターを追加するにあたり、プレイヤー用と敵用の変数を個別に定義すると、3 体目以降を追加するたびにデータ構造が肥大化してしまう。

## 決めたこと

キャラクターを固定長配列として一括管理する。
- 配列の先頭（インデックス 0）をプレイヤー、次以降の要素を敵キャラクターとする。
- `SceneState` にキャラクターごとの個別フィールドを増やさず、ループ処理で一括描画・更新する。
- プレイヤーの初期座標は `(0, 0, 0)`、ヨー角 0 度。敵の初期座標は `(0, 0, 4)`、ヨー角 180 度（プレイヤーと正対する向き）。
- 頂点バッファは共通の立方体メッシュを使い回し、マテリアル色のみキャラクターごとに分ける（面ごとの塗り分けは行わない）。
- この時点での移動操作（WASD）およびカメラ注視点はプレイヤーのみを対象とし、敵キャラクターは静止したままとする。

## 採らないこと

敵の自律移動、攻撃判定、外壁、重力演算、汎用エンティティシステム、個別ポリゴンメッシュ、基底クラスや継承構造。
