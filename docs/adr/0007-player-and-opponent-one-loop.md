## 文脈

`SceneState` は立方体が一つである。位置、回転、クリア色、カメラ、歩行モードだけを持つ。描くものはライティングした立方体一つと、その下の床一枚。

プレイヤー用と相手用にフィールドを分けると、三人目でまたフィールドが増える。ECS、階層、コンポーネントで分ける段階ではない。

## 決定

主体は並びで持つ。先頭がプレイヤー、次が相手である。三人目は要素を足す。`SceneState` に主体ごとのフィールドは足さない。

各主体は位置とヨーを持つ。ピッチとロールは、パネルが今編集している回転の残りとして、その主体に残す。プレイヤーの初期位置と回転は今のまま、原点でヨー 0 である。相手の初期位置は `(0, 0, 4)` である。ヨー 0 は +Z を向くので、相手のヨーは 180 度とし、プレイヤーのいる -Z を向く。相手のピッチとロールは 0 である。

見た目は今の立方体のメッシュのまま、二人で同じ頂点を描く。立方体全体の色だけ主体ごとに分ける。面ごとの色は付けない。プレイヤーの色は今の `(0.78, 0.48, 0.27)` のままである。相手は `(0.25, 0.42, 0.68)` の一色である。

WASD はプレイヤーだけを動かす。既定は自分のヨー、切り替えでカメラのヨーである。速さ、経過時間の上限、Y を変えないことは 0004 と 0005 のままである。床の端で止まる規則は、この記録ではプレイヤーにだけ残す。相手は動かない。

カメラは今の球面のまま、プレイヤーの位置を見る。パネルが編集するのはプレイヤーの位置と回転である。

攻撃、相手の移動、壁、重力、落下、物理ライブラリ、アニメーション、主体の種類ごとのメッシュは含めない。

## 結果

- 二人の立方体が同じループで描かれる。色で区別できる。
- 歩行、床の端、カメラの注視点、パネルはプレイヤーだけを見る。相手は初期位置から動かない。
- 三人目は並びの要素である。`SceneState` に専用のフィールドは生やさない。
