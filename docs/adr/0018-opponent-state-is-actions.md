# 相手の状態は、歩きと攻撃する／しないの組み合わせである

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [相手の状態を ADR に残す](https://github.com/momora-m/kamae/issues/53)

## なぜ

近づいて撃つ以外を足すとき、新しい攻撃の関数にはしない。届ける入力の組み合わせとして足す。

## 決めたこと

相手の状態は、水平の歩きと、攻撃する／しないの組み合わせである。新しい `Attack` は作らない。撃つときも、今と同じ `Attack` に攻撃するを渡す。

最初の状態は三つまでである。

- 近づく。プレイヤーの XZ へ歩く。攻撃はしない。
- 間合いで待つ。歩きは出さない。攻撃はしない。初撃の待ちは、この状態のあいだに進む。
- 撃つ。歩きは出さない。攻撃するを、同じ `Attack` に渡す。繰り返しの間隔は `Attack` が見る。

回り込むと下がるは、別の状態にしない。歩きの向きを変えるだけである。この記録では、その向きは足さない。最初に出荷するのは、近づく、間合いで待つ、撃つの三つである。

見た目の接近、ヨー、ヒットボックス、体力、間隔の数字は変えない。

## 採らない

攻撃の溜め。無敵。エンティティとコンポーネント。コントローラーの GUI。新しい `Attack`。
