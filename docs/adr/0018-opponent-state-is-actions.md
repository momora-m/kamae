# 相手の状態は、歩きと攻撃する／しないの組み合わせである

- 状態: `accepted`
- 日付: 2026-09-26
- 作業: [相手の状態を ADR に残す](https://github.com/momora-m/kamae/issues/53)

## 文脈

[0017](0017-actions-reach-subjects.md) で、試走中の主体が受け取るのは水平の歩きと、攻撃する／しないだけである。プレイヤーはキーからそれを作る。相手は `ApproachAndAttack` が、今の接近の結果から撃つかどうかを作り、同じ `Attack` を呼ぶ。状態という名前はない。

間隔、先行入力、初撃の待ちは [0016](0016-winnable-trial-attack.md) のままである。攻撃の溜め、無敵、コンボは [0015](0015-edit-then-start-a-trial.md) のまま採らない。

近づいて撃つ以外を足すとき、新しい攻撃の関数にはしない。届ける操作の組み合わせとして足す。

## 決定

相手の状態は、0017 の水平の歩きと、攻撃する／しないの組み合わせである。新しい `Attack` は作らない。撃つときも、今と同じ `Attack` に攻撃するを渡す。

最初の状態は三つまでである。

- 近づく。プレイヤーの XZ へ歩く。攻撃はしない。
- 間合いで待つ。歩きは出さない。攻撃はしない。初撃の待ちは 0016 のまま、この状態のあいだに進む。
- 撃つ。歩きは出さない。攻撃するを、同じ `Attack` に渡す。繰り返しの間隔は 0016 のまま、`Attack` が見る。

回り込むと下がるは、別の状態にしない。歩きの向きを変えるだけである。この記録では、その向きは足さない。最初に出荷するのは、近づく、間合いで待つ、撃つの三つである。

見た目の接近、ヨー、箱、残り、間隔の数字は変えない。実装は次の issue である。

攻撃の溜め、無敵、ECS、コントローラーの GUI、箱の寿命、時間の止め方は、ここには含めない。

## 結果

- 相手の状態は、主体に届く歩きと、攻撃する／しないの組み合わせである。
- 最初に名前があるのは、近づく、間合いで待つ、撃つ、だけである。
- 回り込むと下がるは、歩きの向きである。新しい攻撃にはならない。
- 溜め、無敵、箱の寿命、ヒットストップは、この記録では増えない。
