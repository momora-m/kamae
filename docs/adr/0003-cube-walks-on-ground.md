# 立方体を床の上で歩かせる

- 状態: `accepted`
- 日付: 2026-09-23
- 言葉: [../words.md](../words.md)
- 置き換え: 進行方向をカメラのヨーにすることと、歩行中にヨーを移動方向へ向けることは [0004](0004-cube-walks-its-facing.md) が置き換えた。床、速さ、経過時間、Y を変えないこと、カメラの周回は、ここがいまの判断である。

## なぜ

立方体は見えている。足りないのは、フレームごとの移動と、その移動が見える床である。

## 決めたこと

ビューポートにカーソルがあるとき、WASD で立方体を XZ の上で動かす。前後左右は、カメラが見ている水平方向である。斜め入力は速さを増やさない。速さは秒あたり 2.5。立方体の一辺は 1。経過時間はウィンドウのループで測り、1 フレームは 0.1 秒を超えない。Y は変えない。

動いているあいだ、ヨーは移動方向を向く。ピッチとロールはパネルの値のまま。止まっているときはヨーを保つ。

カメラの回り方は変えない。見る位置は立方体である。

床は `Renderer` の中の板一枚である。一辺は 40。上面は立方体の底よりわずかに下。同じ頂点シェーダ、ピクセルシェーダ、定数バッファで描く。`SceneState` には入れない。

## 採らない

アニメーション。当たり判定。二体目のメッシュ。入力の抽象化。レベルデータ。床を二枚にすること。

## あとから

進行方向と、歩行がヨーを上書きすることは 0004 が置き換えた。床と速さの数字は、ここから変えていない。
