# 立方体を床の上で歩かせる

- 状態: `accepted`
- 日付: 2026-09-23
- 置き換え: 進行方向をカメラのヨーにする決定と、歩行中にヨーを移動方向へ向ける決定は [0004](0004-cube-walks-its-facing.md) が置き換えた。床、速さ、経過時間、Y を変えないこと、カメラの周回はここが現在の決定である。

## 文脈

最初の画面は Windows で起動しています。立方体がひとつあり、カメラはすでにその位置を見ています。ビューのドラッグで周りを回り、距離はパネルにあります。

足りないのは、フレームごとの移動と、その移動が見える床です。

## 決定

ビューポートにカーソルがあるとき、WASD で立方体を XZ 平面上で動かします。前後左右は、カメラが見ている水平方向です。W はその向き、D は右です。斜め入力は正規化し、速さは増やしません。速さは秒あたり 2.5 で、立方体の一辺は 1 です。経過時間はウィンドウのループで測ります。1 フレームは 0.1 秒を超えないようにします。Y は変えません。

動いているあいだ、ヨーは移動方向を向きます。ピッチとロールはパネルの値のままです。止まっているときは、ヨーをそのまま保ちます。

カメラは今の周回のままです。注視点は立方体の位置です。

床は `Renderer` の中の板一枚です。一辺は 40 で、上面は立方体の底よりわずかに下に置きます。同じ頂点シェーダ、ピクセルシェーダ、定数バッファで描きます。`SceneState` には入れません。

アニメーション、当たり判定、二体目のメッシュ、入力の抽象化、レベルデータは含めません。

## 結果

- 位置とヨーは、これまでどおり `SceneState` の立方体の値です。パネルからも変えられます。歩いているフレームは、ヨーを移動方向で上書きします。
- 床の描画は `Renderer` の中で終わらせます。DirectX の型は外へ出しません。
- 床をレベルや二枚目の板に広げることは、この記録に含めません。
