# パネルで相手を増減する

- 状態: `accepted`
- 日付: 2026-09-24

## 文脈

[0007](0007-player-and-opponent-one-loop.md) の主体は並びである。先頭がプレイヤー、次が相手の一人で、人数はコードの定数である。

[0012](0012-edit-subject-pose.md) で、パネルは位置とヨーを編集できる。増減はできない。

二人目の相手を、コードを変えずにパネルから足せるようにする。プレイヤーは消さない。上限を決めて、生成装置にはしない。

## 決定

主体は固定長の配列のまま、使う人数だけを変える。配列の長さは 4 である。先頭の 1 人はプレイヤーで、パネルから消せない。相手は 0 人から 3 人までである。初期の人数は 2 で、今のプレイヤーと相手である。再起動すると、この人数と配置に戻る。ファイルには書かない。

足した相手の位置は `(0, 0, 4)`、ヨーは 180 度、色は今の相手の `(0.25, 0.42, 0.68)`、残りは 3、攻撃のクールダウンは 0 である。同じ場所にすでに主体がいても、重なったまま置く。その場では解消しない。次に動いたときの、壁と他の主体への重なり解消に任せる。

消せるのは末尾の一人だけである。残りが 0 で描かれなくなった主体も、並びからはこの操作でしか外さない。末尾を消すと、使う人数が 1 減る。

足した主体も、先頭の XZ へ [0011](0011-opponent-same-attack.md) と同じ接近と攻撃をする。プレイヤーの色、歩行、攻撃、カメラは変えない。相手が 0 人でも、プレイヤーは歩ける。

増減の手続きは別の翻訳単位に置く。ボタンは [0012](0012-edit-subject-pose.md) のパネルに足し、`main.cpp` には足さない。`Character` 基底や Player / Opponent 型は作らない。

保存と読み込み、床の大きさ、壁を個別に置くこと、相手ごとの技、色の編集、4 人を超える配置は含めない。

## 結果

- 相手を足すと立方体が増える。相手が 3 人のときは、それ以上足せない。
- 末尾を消すと減る。プレイヤーは残る。相手が 0 人でもプレイヤーは歩ける。
- 再起動すると、コードに書いた二人に戻る。
