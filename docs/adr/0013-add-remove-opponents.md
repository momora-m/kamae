# パネルで相手を増減する

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

二人目の相手を、コードを変えずにパネルから足せるようにする。プレイヤーは消さない。上限を決めて、生成装置にはしない。

## 決めたこと

キャラクターは固定長の配列のまま、使う人数だけを変える。配列の長さは 4。先頭の 1 人はプレイヤーで、パネルから消せない。相手は 0 人から 3 人まで。初期の人数は 2。再起動すると、この人数と配置に戻る。ファイルには書かない。

足した相手の位置は `(0, 0, 4)`、ヨーは 180 度、色は `(0.25, 0.42, 0.68)`、残りは 3、攻撃のクールダウンは 0。同じ場所にすでにキャラクターがいても、重なったまま置く。その場では解消しない。次に動いたときの、壁と他のキャラクターへの重なり解消に任せる。

消せるのは末尾の一人だけである。残りが 0 で描かれなくなったキャラクターも、並びからはこの操作でしか外さない。

足したキャラクターも、先頭の XZ へ同じ接近と攻撃をする。相手が 0 人でも、プレイヤーは歩ける。

増減の手続きは、位置とヨーのパネルに足し、`main.cpp` には足さない。`Character` 基底は作らない。

## 採らない

保存と読み込み。床の大きさ。壁を個別に置くこと。相手ごとの技。色の編集。4 人を超える配置。
