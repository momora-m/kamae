# パネルで相手を増減する

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

複数の敵キャラクターとの対戦バランスを検証するため、コードを変更することなく GUI から敵の人数を増減できるようにする。

## 決めたこと

- キャラクターの配列長は 4 の固定長配列とする（最大 4 体）。
- 先頭の 1 体はプレイヤーであり、パネルから削除することはできない。
- 敵キャラクターは 0 体から 3 体までの範囲で増減可能とする（起動時の初期敵人数は 1 体）。
- 敵を追加した場合、初期座標 `(0, 0, 4)`、ヨー角 180 度、標準マテリアル色、体力 3、クールダウン 0 で生成する。既存のキャラクターと座標が重なる場合でもその場での強制押し出しは行わず、移動時の衝突解消処理に任せる。
- 削除操作は常に配列末尾の 1 体のみを対象とする。体力が 0 になって倒された敵も、明示的に削除操作を行うまでは配列要素として維持される。
- 追加された敵キャラクターも、先頭プレイヤーへ向けて同一の追従接近・攻撃処理を実行する。敵が 0 体の場合でもプレイヤーは単独で自由に歩行・攻撃できる。

## 採らないこと

5 体以上のキャラクター配置、敵ごとの異なるステータスや攻撃パターンの割り当て、キャラクターの途中挿入・任意スロット削除。
