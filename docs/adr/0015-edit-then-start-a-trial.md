# 編集と試走を分け、名前付きの配置から始める

- 状態: `accepted`
- 日付: 2026-09-25
- 作業: 次の順で実装する。編集と開始を分ける。シーンを複数保存し、編集中に選んで読み込める。プレイヤー1対相手1の初期状態を定義し、攻撃の届かない位置から戻せる。プレイヤーか相手の全滅で試走を止め、開始状態へ戻す操作を出す。

## 文脈

[0011](0011-opponent-same-attack.md) で、相手はプレイヤーの XZ へ歩き、攻撃の箱が届く距離で同じ攻撃を出す。起動した時点からこの移動は進む。[0012](0012-edit-subject-pose.md) で、パネルが書いた位置はそのフレームの歩行と攻撃に効く。[0014](0014-save-arena-layout.md) は、作業ディレクトリの `arena.txt` 一つに床の半辺と主体の配置を書き、起動時に読み戻す。相手は [0013](0013-add-remove-opponents.md) のまま 0 人から 3 人までである。

配置を直しているあいだも相手が歩き、攻撃する。開幕の間合いは、攻撃の溜めで空けない。初期の位置だけで、攻撃の箱が届かないところから試走を始める。

## 決定

編集と試走は別である。起動したときは編集である。編集中は時間を止める。相手は歩かず、攻撃しない。プレイヤーの歩行と攻撃も進めない。パネルでの配置の変更は時間ではない。試走は、ユーザーが開始を明示したときだけ始まる。試走中はシーンを切り替えない。試走中に配置を編集する操作は出さない。

開始したとき、そのとき編集している配置を開始状態として覚える。保存していない変更も、開始を押したときの配置なら開始状態に入る。開始状態はシーンの配置であり、戦闘の途中経過ではない。開始したときの各主体の残りは 3、クールダウンは 0 である。

プレイヤーの残りが尽きたとき、試走を止める。使っている相手が 1 人以上いて、その全員の残りが尽きたときも止める。相手が 0 人のときは、相手の全滅では止めない。止めたあとは、自動では開始状態に戻さない。尽きたあとの画面を残す。残りが 0 の主体を描かないことは [0009](0009-attack-reduces-remaining.md) のままである。戻す操作を出し、その操作で開始状態の配置に戻し、編集に戻る。試走は自動では再開しない。

組み込みの初期状態を、保存したシーンとは別にコードで持つ。プレイヤー 1 人と相手 1 人である。プレイヤーは `(0, 0, 0)`、ヨーは 0 度、色は `(0.78, 0.48, 0.27)` である。相手は `(0, 0, 4)`、ヨーは 180 度、色は `(0.25, 0.42, 0.68)` である。床の半辺は 20 である。この二点では、[0009](0009-attack-reduces-remaining.md) の攻撃の箱は届かない。前方 1.0、左右は中心から 0.5、という箱のままである。攻撃の溜めは入れない。間合いはこの初期位置だけで空ける。

初期状態に戻す操作は、編集中に、今の配置をこの 1 対 1 で置き換える。床の半辺も 20 に戻す。保存してあるシーンは消さない。保存したシーンが、この組み込みの初期状態を上書きすることはない。試走中にはこの操作を出さない。

シーンは名前を付けて複数保存できる。編集中に一覧から一つ選んで読み込む。読み込んだシーンが、次の開始状態になる。一つのシーンが持つデータは、今の `arena.txt` と同じ種類である。`floor` と床の半辺、主体の位置、ヨー、色。先頭の行がプレイヤーである。残り、攻撃のクールダウン、ピッチ、ロール、カメラ、クリア色は書かない。読み込んだ主体の残りは 3、クールダウンは 0、ピッチとロールは 0 である。相手は 0 人から 3 人までである。行が壊れている、数が範囲外、主体が 0 人または 5 人以上のときは読み込まず、今の配置を保ち、失敗を出す。この拒否は [0014](0014-save-arena-layout.md) と同じである。

`arena.txt` 一つへ上書きする保存と、起動時にそのファイルを読んで配置を置き換え、試走を始めることは、ここが置き換える。既にある `arena.txt` は消さない。起動時には読まない。

攻撃の溜め、無敵時間、コンボ、試走中の編集は含めない。溜めは後に回すのではなく、採らない。

## 結果

- 起動しても相手は歩かない。開始を押してから試走が始まる。
- プレイヤーの残りが尽きるか、相手が全員尽きると試走が止まる。配置は自動では戻らない。戻す操作で、開始したときの配置になり、編集に戻る。
- 初期状態に戻すと、攻撃の届かない 1 対 1 になる。保存したシーンは残る。
- 編集中に別のシーンを読むと、次の試走はその配置から始まる。試走の途中ではシーンを切り替えられない。
