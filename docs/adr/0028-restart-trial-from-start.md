# 停止中に、同じ開始状態からもう一度プレイを始める

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [停止中に、同じ開始状態からもう一度プレイを始める](https://github.com/momora-m/kamae/issues/88)

## なぜ

プレイが止まると、配置は残る。もう一度見るには、Return to start で編集モードへ戻り、Start を押し直す必要があった。停止中に、覚えてある開始状態からプレイを始め直せるようにする。

## 決めたこと

停止中だけ、Play again を出す。押したフレームに、開始状態の配置へ戻してプレイを始める。各キャラクターの体力は 3、クールダウンは 0 である。先行入力、間合いの待ち、後退、ヒットストップは消す。止まったあとの配置は、開始状態として覚え直さない。

停止理由の一文は、そのフレームでは出さない。Return to start は、今どおり編集モードに戻す。自動では再開しない。プレイ中と編集中には、この操作を出さない。

## 採らないこと

スコア、ラウンド数、勝者有利、配置の編集。開始状態を取り直すことも、この操作ではしない。
