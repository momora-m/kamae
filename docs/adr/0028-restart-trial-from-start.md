# 停止中に、同じ開始状態からもう一度プレイを始める

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [停止中に、同じ開始状態からもう一度プレイを始める](https://github.com/momora-m/kamae/issues/88)

## なぜ

プレイモードが停止した後、同一の配置でもう一度対戦を検証するためには、一度「Return to start」で編集モードへ戻った上で再度「Start」ボタンを押下する必要があり、試行錯誤のテンポを阻害していた。停止画面から直接、直前の開始時の配置（開始状態）を維持したまま即座に再戦を開始できるようにする。

## 決めたこと

プレイモード停止中（`SessionMode::Stopped`）の Subjects パネルに「再戦（Play again）」操作を追加する。

- **即時再戦の挙動**:
  - `Play again` ボタンを押下したフレームで、記憶している開始状態（`StartLayout`）の配置へ全キャラクターを復元し、プレイモード（`SessionMode::Trial`）へ直接遷移する。
  - 各キャラクターの体力は 3、クールダウンは 0 秒へ初期化し、先行入力バッファ、間合い待ちタイマー、後退フラグ、被弾ヒットストップ残フレームはすべてクリアする。
  - 停止時点の座標で開始状態を上書き保存することはしない。
- **UI 表示と復帰の整理**:
  - 再開と同時に停止状態が解除されるため、[0024](0024-trial-stop-is-a-result.md) の停止理由テキストは即座に非表示となる。
  - 従来の「開始状態に戻す（Return to start）」操作は引き続き維持し、編集モードへの復帰手段として提供する。
  - プレイモード中および編集モード中には `Play again` 操作は表示しない。自動で再開する処理は含めない。

## 採らないこと

勝敗に応じたハンディキャップ付与、連続対戦スコアやラウンド数の記録、停止画面からの配置編集。
