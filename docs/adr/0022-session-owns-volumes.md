# ヒットボックスはプレイが持つ並びにある

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [箱を試走が持つことを ADR に残す](https://github.com/momora-m/kamae/issues/67)

## なぜ

ヒットボックスがキャラクターと同じ長さの枠にあると、ヒットボックスがプレイのものであることが隠れる。並べる画面の話ではない。

## 決めたこと

ヒットボックスはプレイが持つ並びへ出る。`Attack` はキャラクターの枠へ書かない。出したヒットボックスは、その並びの要素である。

寿命はフレーム数のままである。判定と描画は、その並びの同じヒットボックスを見る。別の表示用は作らない。出したときの判定の形のままその場に残る。

並びの長さは、今使っているキャラクターの人数を超えなければ足りる。クールダウンが寿命より長いので、一つのキャラクターが同時に二つは持たない。満杯のときは出さない。

編集モードに戻ると並びを空にする。開始と、配置の読み込みでも空にする。プレイを止めたあとも、残フレームのあいだは並びのヒットボックスを描く。

## 採らない

ヒットの適用を `Attack` の外へ出すこと。寿命の数字の変更。新しい種類のヒットボックス。エンティティとコンポーネント。
