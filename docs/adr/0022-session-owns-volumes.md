# 攻撃の箱は試走が持つ並びにある

- 状態: `accepted`
- 日付: 2026-09-26
- 作業: [箱を試走が持つことを ADR に残す](https://github.com/momora-m/kamae/issues/67)
- 追加: その並びの重なりを当たりとして試走が適用することは [0023](0023-hit-is-session-result.md)。箱が試走の並びにあることは、ここが現在の決定である。

## 文脈

[0019](0019-attack-volume-lifetime.md) で、攻撃の箱は 3 フレームの寿命を持ち、判定と描画が同じ区間を見る。箱は主体と同じ長さの槽にあり、`Attack` は攻撃した主体の槽へ書く。次の攻撃はその槽を上書きする。

コントローラーが主体に付くことは [0021](0021-controller-attaches-to-subject.md) のままである。箱の寿命、当たる区間、同じ箱は一度だけ、出した場所に残ることは 0019 のままである。

主体の槽は、箱が試走のものであることを隠す。GUI で箱を並べる話ではない。

## 決定

攻撃の箱は試走が持つ並びへ出る。`Attack` は主体の槽へ書かない。出した箱は、その並びの要素である。

寿命は 0019 のフレーム数のままである。判定と描画は、その並びの同じ箱を見る。別の表示用の箱は作らない。箱は出したときの判定の箱のままその場に残る。

並びの長さは、今使っている主体の人数を超えなければ足りる。クールダウンが寿命より長いので、一つの主体が同時に二つは持たない。満杯のときは出さない。

編集に戻ると並びを空にする。開始と、配置の読み込みでも空にする。試走を止めたあとも、残フレームのあいだは並びの箱を描く。

当たりの適用を `Attack` の外へ出すことは、ここには含めない。寿命の数字、新しい箱の種類、ECS は含めない。実装は次の issue である。

## 結果

- 箱は試走が持つ並びに出る。主体の槽には無い。
- 寿命、当たる区間、同じ箱は一度だけ、は 0019 のままである。
- 描画もその並びを見る。
- 当たりの適用の切り出し、寿命の数字、新しい箱は増えない。
