# ガードするとヒットボックスは体力を減らさない

- 状態: `accepted`
- 日付: 2026-09-27
- 言葉: [../words.md](../words.md)
- 作業: [ガードするとヒットボックスは体力を減らさない](https://github.com/momora-m/kamae/issues/98)

## なぜ

ヒットボックスが重なると、必ず体力が 1 減る。防ぐ入力がないため、正面からの打ち合いは先に判定が出た側が勝つだけになる。コントローラーの入力へガードを足し、正面からの重なりでは体力を減らさないようにする。発生と硬直を入れたあとでこれを足す。隙のない連打を防いでも、守りより連打のほうが速いままになる。

## 決めたこと

コントローラーが出す入力に、ガードする／しないを足す。技の番号とは別に持つ。プレイヤーと相手は同じ入力を見る。

- **入力と操作**:
  - プレイヤーは Shift を押しているあいだガードする。左右のどちらの Shift でもよい。
  - ガード中は歩けない。新しい技も出ない。同じフレームで技のキーが押されても、ガードが残っていれば技は出ない。
  - 発生・持続・硬直の途中では、ガードは始まらない。途中の技をガードで取り消すことはしない。
  - 先行入力は、クールダウンの最後 0.15 秒だけ覚える規則のまま扱う。
- **正面の判定**:
  - ガード中、自分のヨーの前方から重なったヒットボックスは体力を減らさない。
  - 前方とは、キャラクターの中心からヒットボックスの中心へ向かう水平ベクトルと、ヨーの前向きとの内積が正であることとする。内積が 0 以下の横と後ろは、今どおり体力を 1 減らす。
  - 防いだヒットには、4 フレームのヒットストップを置かない。
  - 同じヒットボックスは、防いでもそのキャラクターをもう一度見ない。
- **相手**:
  - 相手は、撃つフレームに限って、プレイヤーの短い技か長い技のヒットボックスが自分に重なるとき、攻撃の代わりにガードする。後退は始めない。
  - 間合いに入ってからの 0.5 秒待ちのあいだは、今どおり立ち止まるだけである。その待ちのあいだにプレイヤーの判定が重なれば、今どおり当たる。

## 採らないこと

ガード崩し、削り、パリィ、無敵、回避、押し出し、速度、物理ライブラリ、アニメーション。ガードの向きをヨー以外の軸で見ることも採らない。
