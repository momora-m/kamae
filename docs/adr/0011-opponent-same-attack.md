# 相手は同じ攻撃でプレイヤーを倒す

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: 攻撃間隔をプレイヤーと同一の 0.4 秒とする仕様は、後続の [0016](0016-winnable-trial-attack.md)（プレイヤー先行入力と敵の初撃遅延）によって置き換えられた。敵の追従・接近および同一ルールでの攻撃実行は本決定を維持する。

## なぜ

プレイヤーが一方的に攻撃するサンドバッグ状態から脱却し、相互に倒し合えるアクション戦闘を成立させる。

## 決めたこと

敵キャラクターに自律行動（接近と攻撃）を実装する。
- 敵はプレイヤーの XZ 座標へ向けて一定速度（プレイヤーと同じ 2.5/秒）で直線移動する。移動中は自身のヨー角を移動方向へ向ける。
- 敵の攻撃ヒットボックスがプレイヤーに重なる間合いに到達した場合、移動を停止し、ヨー角をプレイヤーへ向けて同一の攻撃を実行する。
- プレイヤーの初期体力も敵と同様に 3 とし、被弾により体力が 1 ずつ減少する。プレイヤーの体力が 0 に達した場合は死亡扱いとなり、描画を停止し移動・攻撃ともに不能となる（敵の行動も停止する）。
- 敵の移動衝突解消には、[0008](0008-walk-stops-before-wall-and-subject.md) と同一の軸別スライド処理を適用する。
- アリーナ内部は凸形状であり外壁以外の遮蔽物がないため、経路探索（ナビメッシュ）は導入せず直線追従とする。
- 敵の体力が先に尽きた場合、敵の行動のみが停止し、プレイヤーはそのまま操作可能とする。

## 採らないこと

勝敗リザルト演出、コンティニュー画面、重力・落下処理、ナビゲーションメッシュ、複数攻撃技の使い分け。

## 後続の更新

間合い到達後の攻撃発生タイミング（初撃 0.5 秒待ち、繰り返し 0.8 秒間隔）は [0016](0016-winnable-trial-attack.md) で改定された。
