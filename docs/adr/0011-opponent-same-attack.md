# 相手は同じ攻撃でプレイヤーを倒す

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: 範囲にいるあいだ 0.4 秒に一度出すことは [0016](0016-winnable-trial-attack.md) が置き換えた。出したフレームだけ残すことは [0019](0019-attack-volume-lifetime.md) が置き換えた。接近、ヒットボックスの形、体力、接触では減らないことは、ここがいまの判断である。

## なぜ

一つのアリーナの倒し合いにする。相手もプレイヤーへ近づき、同じ攻撃でプレイヤーを倒せる。重力、落下、経路探索はこの判断に入れない。

## 決めたこと

相手はプレイヤーの XZ へ向かって歩く。速さはプレイヤーと同じ秒あたり 2.5。移動したフレームのヨーは、その移動方向を向く。ピッチとロールは変えない。Y は変えない。

立ち止まる距離は、相手のヨーをプレイヤーへ向けたときの、プレイヤーと同じ攻撃のヒットボックスである。それがプレイヤーに重なるときは、そのフレームは歩かず、ヨーをプレイヤーへ向け、同じ攻撃を出す。範囲にいるあいだ、押した扱いは 0.4 秒に一度である。ビューポートや文字入力では止めない。

プレイヤーと相手が同じフレームに出したときは、両方のヒットボックスを描く。

プレイヤーの体力は 3 から始まる。届くと 1 減る。0 のプレイヤーは描かない。歩行も攻撃もしない。相手の移動と攻撃も止まる。

歩きながらの接触では減らない。動いたあとに、壁か他のキャラクターへ重なった軸の移動だけ取り消す。解消はプレイヤーと同じである。

床の内側は凸なので、二人のあいだの直線は壁に遮られない。ナビメッシュは作らない。

相手の体力が先に 0 になったら、相手の移動と攻撃は止まる。プレイヤーの歩行と攻撃はそのままである。

この接近と、範囲に入ったときに攻撃へ切り替える判断は、`main.cpp` とは別のファイルに置く。`Character` 基底や Player / Opponent 型は作らない。
