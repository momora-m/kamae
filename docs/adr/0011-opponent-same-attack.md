# 相手は同じ攻撃でプレイヤーを倒す

- 状態: `accepted`
- 日付: 2026-09-24

## 文脈

[0009](0009-attack-reduces-remaining.md) で攻撃するのはプレイヤーだけである。相手は [0007](0007-player-and-opponent-one-loop.md) の初期位置 `(0, 0, 4)` に立ち、残りが尽きると描かれず、歩行の障害にも攻撃の対象にもならない。プレイヤーの残りは減らない。

[0010](0010-attack-box-one-frame.md) で、攻撃を出したフレームだけ、その判定と同じ箱を描く。

一つのアリーナの倒し合いにする。相手もプレイヤーへ近づき、同じ攻撃でプレイヤーを倒せる。重力、落下、経路探索はこの決定に入れない。

## 決定

相手はプレイヤーの XZ へ向かって歩く。速さはプレイヤーと同じ秒あたり 2.5 である。移動したフレームのヨーは、その移動方向を向く。ピッチとロールは変えない。Y は変えない。

立ち止まる距離は、相手のヨーをプレイヤーへ向けたときの、プレイヤーと同じ攻撃の箱である。その箱がプレイヤーの箱と重なるときは、そのフレームは歩かず、ヨーをプレイヤーへ向け、同じ攻撃を出す。前面から前方 1.0、左右は中心から 0.5、面が触れるだけでは重ならないことは 0009 のままである。範囲にいるあいだ、押した扱いは 0.4 秒に一度である。ビューポートにカーソルがあるか、文字入力がキーを取っているかでは止めない。

出したフレームの箱は 0010 のまま、主体とは別の一色で、次のフレームには残さない。プレイヤーと相手が同じフレームに出したときは、両方の箱を描く。

プレイヤーの残りは 3 から始まる。届くと 1 減る。0 のプレイヤーは描かない。歩行も攻撃もしない。相手の移動と攻撃も止まる。

歩きながらの接触では減らない。動いたあとに、壁か他の主体へ重なった軸の移動だけ取り消す。解消はプレイヤーと同じである。

床の内側は凸なので、二人のあいだの直線は壁に遮られない。初期配置も遮られない。ナビメッシュは作らない。

相手の残りが先に 0 になったら、相手の移動と攻撃は止まる。プレイヤーの歩行と攻撃はそのままである。

この接近と、範囲に入ったときに攻撃へ切り替える判断は、別の翻訳単位に置く。`main.cpp` はウィンドウ手続きとフレームの呼び出しのままである。主体は並びのままである。`Character` 基底や Player / Opponent 型は作らない。

勝敗の表示、やり直し、重力、落下、物理ライブラリ、アニメーション、複数の技、複数の相手、経路探索は含めない。

## 結果

- 相手が近づき、同じ攻撃でプレイヤーの残りが 1 ずつ減る。3 回でプレイヤーは描かれず、歩けず、攻撃できず、相手も止まる。
- 立方体が触れているだけでは、残りは減らない。
- 先に相手の残りが尽きると、相手は止まり、プレイヤーは歩ける。
