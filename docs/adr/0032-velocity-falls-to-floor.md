# 速度が残り、重力で落ちて床で止まる

- 状態: `accepted`
- 日付: 2026-09-27
- 言葉: [../words.md](../words.md)
- 作業: [速度が残り、重力で落ちて床で止まる](https://github.com/momora-m/kamae/issues/101)

## なぜ

歩きは、そのフレームの水平移動ベクトルだけで位置を足し、次のフレームへ残る速度がなかった。Y は変えず、床の上に固定していた。ガードと発生・硬直を入れたあとに、落下と慣性を速度として書く。当たった力や回避を後から足す土台にする。速度だけ先に足すと、隙もガードもない打ち合いの手触りが先に変わってしまう。

## 決めたこと

キャラクターは水平と垂直の速度を持つ。速度はフレームをまたいで残る。プレイセッションが、フレーム更新時間を掛けて位置へ足す。

- **重力と床**:
  - 毎フレーム、Y の速度へ重力 10 をフレーム更新時間だけ足す。この大きさは、床の上の立方体の高さ 1 から、約半秒で着地する最小に近い値である。
  - 立方体の中心が Y 0 を下回らない。床に着いたフレームは、落ち止まり、そのフレームの Y の速度を消す。
  - 空中では歩けない。水平の速度は残る。
- **床の上の歩き**:
  - 歩行を進めるフレームは、水平の速度をそのフレームの移動で置き換える。移動が 0 なら、水平の速度も 0 である。
  - 発生、硬直、ガードで歩行しないフレームは、水平の速度を残す。
- **重なり**:
  - 壁か他のキャラクターに重なった軸は、今どおり位置を戻し、戻した軸の速度も消す。
- **開始と保存**:
  - 編集へ戻る、プレイを始める、やり直す、では速度を消す。シーンと開始状態には速度を書かない。読み込んだキャラクターの速度は 0 である。

## 採らないこと

物理ライブラリ、回避、捕食、銃、当たった力を速度へ足すこと、摩擦、ラグドール、積み上げ、反発。当たった力は、このあとの段で足す。

## 後続の更新

当たった力は [0033](0033-hit-adds-velocity.md) で、水平速度へ足す。位置を一度ずらすことはしない。防いだヒットは足さない。
