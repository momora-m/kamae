# 攻撃の箱は寿命を持ち、判定と描画が同じ区間を見る

- 状態: `accepted`
- 日付: 2026-09-26
- 作業: [箱の寿命を ADR に残す](https://github.com/momora-m/kamae/issues/55)
- 追加: 当たった主体の Δt を 0 にすることは [0020](0020-subject-frame-dt.md)。箱の寿命はフレーム数のまま、ここが現在の決定である。
- 置き換え: [0010](0010-attack-box-one-frame.md) の「出したフレームだけ」を、この寿命の当たる区間が置き換える。色、判定と同じ箱、面ごとの色を付けないことは 0010 が現在の決定である。

## 文脈

[0010](0010-attack-box-one-frame.md) で、攻撃を出したフレームだけ、その判定と同じ箱を描く。判定もそのフレームだけである。`AttackMark` は次のフレームに残さない。色は `(0.93, 0.82, 0.28)` である。

硬直やヒットストップは、箱が何フレーム残るかとは別である。歩きを止めることは、時間の ADR に任せる。溜めと無敵は [0015](0015-edit-then-start-a-trial.md) のまま採らない。

## 決定

攻撃の箱は寿命を持つ。寿命はフレーム数である。出始め、当たる、終わりは、その寿命の上の区間である。黄色い箱を描く区間と、残りを減らす判定の区間は、同じ寿命を見る。別の表示用の箱は作らない。

最初の寿命は 3 フレームである。出始めは 0 フレーム、当たるは 3 フレーム、終わりは 0 フレームである。出始めと終わりが 0 なので、寿命の全体が当たる区間である。出したフレームから当たり、続く 2 フレームも当たり、合わせて 3 フレームである。これは溜めではない。出始めを 0 にしたので、当たる前の待ちは無い。0010 の「出したフレームだけ」は、この 3 フレームが置き換える。

箱は、出したときの判定の箱のままその場に残る。攻撃した主体の移動には追従しない。

同じ寿命のあいだ、一つの主体の残りは一度だけ減る。箱がその主体を覚え、同じ箱ではもう減らさない。次に出した箱は、また一度減らせる。これは無敵ではない。次の攻撃までの間隔は [0016](0016-winnable-trial-attack.md) のままである。主体にタイマーは足さない。覚えるのは箱の側である。

硬直、ヒットストップ、溜め、無敵、コンボ、主体ごとのタイマーは含めない。主体が歩きを止める長さは、ここでは決めない。

実装は次の issue である。

## 結果

- 箱は 3 フレーム残る。出したフレームを含めて、判定と黄色い箱はその 3 フレームである。
- 出始めと終わりは 0 フレームである。溜めは増えない。
- 同じ箱は、一つの主体の残りを一度だけ減らす。
- ヒットストップと硬直は、この記録には無い。当たった主体の Δt は [0020](0020-subject-frame-dt.md) が決める。箱の寿命はそれとは別に減る。
