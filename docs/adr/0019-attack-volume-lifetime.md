# ヒットボックスは寿命を持ち、判定と描画が同じ区間を見る

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [箱の寿命を ADR に残す](https://github.com/momora-m/kamae/issues/55)
- 置き換え: [0010](0010-attack-box-one-frame.md) の「攻撃を出した 1 フレームだけ表示・判定する」決定を、本 ADR の持続時間管理で置き換える。

## なぜ

攻撃判定が 1 フレームで消失すると攻撃を当てにくく、ゲームとして成立しづらい。ヒットボックスに適切な寿命（アクティブフレーム）を持たせる。なお、被弾側のヒットストップ（硬直時間）はヒットボックスの寿命とは独立した関心事として分離する。

## 決めたこと

ヒットボックスにフレーム単位の寿命を持たせる。ヒットボックスの描画期間と実際の当たり判定有効期間は完全に一致させる（別個の表示用メッシュ等は作らない）。

- **フレームデータ**: 発生 0F、持続 3F、硬直 0F。攻撃発生と同時に判定が出現し、発生フレームを含めて 3 フレーム間持続する。
- **多重ヒット防止**: 同一のヒットボックスが同一キャラクターに重複してダメージを与えないよう、ヒットボックス側にヒット済みの相手を記録する（1 回の攻撃で 1 ヒットのみ）。
- ヒットボックスは攻撃発生時のワールド座標にその場に残り、攻撃者のその後の移動には追従しない。

## 採らないこと

被弾ヒットストップ（[0020](0020-subject-frame-dt.md) で別途決定）、攻撃前の溜め時間、無敵時間、連続コンボ判定、キャラクターごとの無敵タイマー。
