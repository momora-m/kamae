# ヒットボックスは寿命を持ち、判定と描画が同じ区間を見る

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [箱の寿命を ADR に残す](https://github.com/momora-m/kamae/issues/55)
- 置き換え: [0010](0010-attack-box-one-frame.md) の「出したフレームだけ」を、この寿命の当たる区間が置き換える。

## なぜ

硬直やヒットストップは、ヒットボックスが何フレーム残るかとは別である。歩きを止める長さは、ここでは決めない。

## 決めたこと

ヒットボックスは寿命を持つ。寿命はフレーム数である。出始め、当たる、終わりは、その寿命の上の区間である。黄色いヒットボックスを描く区間と、体力を減らす判定の区間は、同じ寿命を見る。別の表示用は作らない。

最初の寿命は 3 フレームである。出始めは 0 フレーム、当たるは 3 フレーム、終わりは 0 フレームである。出始めと終わりが 0 なので、寿命の全体が当たる区間である。出したフレームから当たり、続く 2 フレームも当たり、合わせて 3 フレームである。これは溜めではない。出始めを 0 にしたので、当たる前の待ちは無い。

ヒットボックスは、出したときの判定の形のままその場に残る。攻撃したキャラクターの移動には追従しない。

同じ寿命のあいだ、一つのキャラクターの体力は一度だけ減る。ヒットボックスがそのキャラクターを覚え、同じヒットボックスではもう減らさない。次に出したヒットボックスは、また一度減らせる。これは無敵ではない。キャラクターにタイマーは足さない。覚えるのはヒットボックスの側である。

## 採らない

硬直。ヒットストップ。溜め。無敵。コンボ。キャラクターごとのタイマー。歩きを止める長さ。
