# プレイ中、キャラクターごとに今フレームの秒を渡す

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [時間の止め方を ADR に残す](https://github.com/momora-m/kamae/issues/57)。実装は [試走中の主体に、フレームの Δt を渡す](https://github.com/momora-m/kamae/issues/58)。

## なぜ

全体を止めると、当たっていない相手まで止まる。そうはしない。ヒットボックスの寿命はフレーム数であり、歩きを止める長さとは別である。

## 決めたこと

プレイ中、歩きと攻撃に渡す秒はキャラクターごとである。全体に掛ける倍率にはしない。

通常は、今のフレームの経過秒である。当たったキャラクターは、次のフレームから 4 フレーム、渡す秒が 0 になる。当たるたびに 4 フレームへ戻す。0 になるのは、当たった次のフレームからである。当たったフレームに渡す秒は、そのフレームの更新に入ったときの値のままである。

キーは毎フレーム読んでよい。読んだ結果の水平の歩きと、攻撃する／しないは、今までどおり作る。`WalkCube` と `Attack` に渡す秒は、そのキャラクターの経過秒である。0 秒を渡してよい。0 秒のフレームは、そのキャラクターの歩きと、クールダウンや初撃の待ちを進めない。クールダウンが既に 0 のとき、攻撃するは 0 秒でも届く。これは無敵ではない。

`SceneState` に、キャラクターごとのクールダウン以外のタイマーを足し続けない。秒を 0 にする記憶は、キャラクターの上の残フレーム一つである。シーン全体の時計は足さない。

ヒットボックスの寿命は経過秒では減らさない。寿命はフレームごとに減る。当たったキャラクターに渡す秒が 0 でも、ヒットボックスの寿命は進む。

ここはプレイ中の、当たったキャラクターだけである。編集モードの停止と、プレイを止めたあとの停止は変えない。

## 採らない

全体のヒットストップ。溜め。無敵。編集モードの変更。
