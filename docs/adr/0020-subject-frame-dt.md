# 試走中の主体は、フレームごとの Δt を持つ

- 状態: `accepted`
- 日付: 2026-09-26
- 作業: [時間の止め方を ADR に残す](https://github.com/momora-m/kamae/issues/57)
- 追加: 当たった主体の Δt を 0 にする長さは 4 フレームである。実装は [試走中の主体に、フレームの Δt を渡す](https://github.com/momora-m/kamae/issues/58)。当たるたびに 4 フレームへ戻す。
- 追加: その Δt を試走が当たりの結果として適用することは [0023](0023-hit-is-session-result.md)。長さは、ここが現在の決定である。

## 文脈

編集中と、試走を止めたあとは [0015](0015-edit-then-start-a-trial.md) の `SessionMode` で、歩きも攻撃も進まない。試走中は、全員が同じ経過時間で進む。主体ごとの Δt は無い。

[0019](0019-attack-volume-lifetime.md) の箱の寿命はフレーム数である。当たった主体の歩きを止めることは、箱の寿命には書かなかった。

全体を止めると、当たっていない相手まで止まる。そうはしない。

## 決定

試走中、各主体は今フレームの Δt を持つ。全体に掛ける倍率にはしない。

通常の Δt は、今のフレームの経過秒である。当たった主体は、次のフレームから 4 フレーム、Δt が 0 になる。当たるたびに 4 フレームへ戻す。0 になるのは、当たった次のフレームからである。当たったフレームの Δt は、そのフレームの更新に入ったときの値のままである。

キーは毎フレーム読んでよい。読んだ結果の水平の歩きと、攻撃する／しないは、今までどおり作る。`WalkCube` と `Attack` に渡す秒は、その主体の Δt である。0 秒を渡してよい。0 秒のフレームは、その主体の歩きと、クールダウンや初撃の待ちを進めない。クールダウンが既に 0 のとき、攻撃するは 0 秒でも届く。これは無敵ではない。

`SceneState` に、主体ごとのクールダウン以外のタイマーを足し続けない。Δt を 0 にする記憶は、主体の上の残フレーム一つである。シーン全体の時計は足さない。

箱の寿命は Δt では減らさない。寿命は 0019 のまま、フレームごとに減る。当たった主体の Δt が 0 でも、箱の寿命は進む。

編集中の停止は 0015 のままである。試走を止めたあとも同じである。ここは試走中の、当たった主体だけである。

全体のヒットストップ、溜め、無敵、編集モードの変更は含めない。

## 結果

- 試走中、主体ごとに今フレームの Δt がある。全体の倍率ではない。
- キーは毎フレーム読む。歩きと攻撃に渡す秒は 0 にできる。
- 箱の寿命は Δt と別で、フレームごとに減る。
- 当たった主体は、次のフレームから 4 フレーム、Δt が 0 である。当たるたびに 4 フレームへ戻る。
- 編集中の時計と、試走を止めたあとの停止は変わらない。
