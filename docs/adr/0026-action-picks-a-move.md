# 入力は、どの技を出すかになる

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [入力は、どの技を出すかになる](https://github.com/momora-m/kamae/issues/86)

## なぜ

攻撃の入力は、出すか出さないかだけだった。リーチと間隔は、技の行ではなくコードの定数に分かれていた。二つ目の技を足す前に、コントローラーが渡すものを技の番号にし、リーチと間隔をその行へ移す。この移し替えでは、画面上の挙動を変えない。

## 決めたこと

`SubjectActions` の攻撃は、技の番号である。技を出さない番号を一つ置く。今の突きを表の最初の行にする。前方 1.0、左右は中心から 0.5、次まで 0.4 秒。発生 0 フレーム、持続 3 フレーム、硬直 0 フレームは、行ではなく今までどおり全体の定数である。

プレイセッションはその行から、今と同じヒットボックスと間隔で撃つ。`Attack` は一つである。プレイヤーの Space はその行を出す。終わり 0.15 秒の先行入力は、最後に押した技の番号を覚える。相手が撃つときも、その同じ行を渡す。後退の規則は変えない。間合いの判定も、その行のヒットボックスで見る。

## 採らないこと

二つ目の技、キーの追加、相手の技選択、行ごとのダメージ差、行ごとのヒットストップ差。発生・持続・硬直は、行で分ける必要がまだないので全体の定数のままにする。
