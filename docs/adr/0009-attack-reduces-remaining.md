# 攻撃が届くと体力が減る

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

プレイヤーの攻撃が相手に届いた際、相手の体力を減らし、体力が尽きたキャラクターを戦闘から退場させる最小限の戦闘ルールを成立させる。

## 決めたこと

各キャラクターに体力（初期値 3）を持たせる。

- ビューポートにマウスカーソルがある状態で Space キーを押下したフレームに、プレイヤーが前方に攻撃を繰り出す。キーの長押し連打は無効とし、次の攻撃まで 0.4 秒のクールダウンを設ける。
- 攻撃範囲はキャラクターのヨー角正面方向へ長さ 1.0、幅 1.0（左右各 0.5）、高さ 1.0（上下各 0.5）の軸平行直方体（AABB）とする。
- 移動完了後の位置を基準に、攻撃発生フレームのみ判定を行う。
- 範囲内に存在する他の生存キャラクターの体力を 1 減少させる。1 回の攻撃判定で同一相手から複数回減算することはない。移動による単純接触ではダメージは発生しない。外壁は攻撃判定を遮らない。
- 体力が 0 になったキャラクターは死亡扱いとし、メッシュ描画、移動障害判定、攻撃判定の対象から完全に除外する（配列内のスロット自体は保持する）。

## 採らないこと

敵からの反撃、被弾ノックバック、連続コンボ、複数種類の攻撃技、アニメーションやパーティクル演出、勝敗リザルト画面。
