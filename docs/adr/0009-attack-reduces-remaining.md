# 攻撃が届くと残りが減る

- 状態: `accepted`
- 日付: 2026-09-24

## 文脈

[0007](0007-player-and-opponent-one-loop.md) の主体は並びである。先頭がプレイヤー、次が相手で、相手は `(0, 0, 4)` に立ち、動かない。[0008](0008-walk-stops-before-wall-and-subject.md) で、歩行は壁と他の主体の手前で止まる。攻撃はない。

プレイヤーの攻撃が相手に届くと、相手の残りが減る。残りが尽きれば、その主体はいなくなる。落下、重力、相手の攻撃はこの決定に入れない。

## 決定

各主体は残りを持つ。初期値は 3 である。`SceneState` に主体ごとのフィールドは足さない。種類や基底は足さない。並びは 0007 のままである。

ビューポートにカーソルがあるとき、Space を押したフレームに、プレイヤーが攻撃する。押し続けによる繰り返しは見ない。次の攻撃まで 0.4 秒空ける。待ち時間は主体に置く。この記録ではプレイヤーだけがこの段を実行する。マウスはカメラの周回のままである。文字入力がキーを取っているときは、歩行と同じく攻撃しない。

攻撃の範囲は、攻撃する主体のヨーの前方である。主体の半辺は 0.5 のまま。前面は、中心からヨーの前方へ半辺だけ進んだ面である。そこから前方へ 1.0、左右は中心から 0.5、上下は中心から半辺である。ヨーが世界の軸に乗っていないときは、その範囲の角を含む軸に沿った箱にする。軸に乗っているときは、箱はその範囲と一致する。歩行と、そのあとの重なりの解消が終わった位置で、押したフレームに一度だけ見る。

重なりは、歩行と同じ軸に沿った箱である。面が触れるだけでは重ならない。範囲にいる、自分以外で残りが残っている主体は、残りが 1 減る。一度の攻撃で、一つの主体から減るのは 1 だけである。攻撃した主体の残りは減らない。壁は遮らない。歩きながらの接触では減らない。

残りが 0 の主体は、描かない。歩行の障害にしない。攻撃の対象にしない。並びの要素としては残す。

相手の攻撃、ノックバック、コンボ、複数の技、アニメーション、エフェクト、勝敗の表示、やり直しは含めない。

## 結果

- 相手の前で Space を押すと、相手の残りが 3 から 1 ずつ減る。3 回で相手は描かれず、歩行も攻撃もそこを見ない。
- 範囲の外、および 0.4 秒より短い連打では減らない。
- プレイヤーの残りは 3 のままである。
