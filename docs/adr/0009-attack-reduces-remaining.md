# 攻撃が届くと体力が減る

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

プレイヤーの攻撃が相手に届くと、相手の体力が減る。体力が尽きれば、そのキャラクターはいなくなる。落下、重力、相手の攻撃はこの判断に入れない。

## 決めたこと

各キャラクターは体力を持つ。初期値は 3。種類や基底は足さない。

ビューポートにカーソルがあるとき、Space を押したフレームに、プレイヤーが攻撃する。押し続けの繰り返しは見ない。次の攻撃まで 0.4 秒空ける。待ち時間はキャラクターに置く。この記録ではプレイヤーだけが攻撃する。文字入力がキーを取っているときは攻撃しない。

攻撃の範囲は、攻撃するキャラクターのヨーの前方である。半辺は 0.5。前面は、中心からヨーの前方へ半辺だけ進んだ面。そこから前方へ 1.0、左右は中心から 0.5、上下は中心から半辺。ヨーが世界の軸に乗っていないときは、その範囲の角を含む、軸に沿った直方体にする。軸に乗っているときは、その範囲と一致する。歩いたあとの位置で、押したフレームに一度だけ見る。

重なりは、歩行と同じ軸に沿った直方体である。面が触れるだけでは重ならない。範囲にいる、自分以外で体力があるキャラクターは、体力が 1 減る。一度の攻撃で、一つのキャラクターから減るのは 1 だけ。攻撃した側の体力は減らない。壁は遮らない。歩きながらの接触では減らない。

体力が 0 のキャラクターは、描かない。歩行の障害にしない。攻撃の対象にしない。並びの要素としては残す。

## 採らない

相手の攻撃。ノックバック。コンボ。複数の技。アニメーション。エフェクト。勝敗の表示。やり直し。
