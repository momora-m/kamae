# 判定と同じヒットボックスを描く

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: 出したフレームだけ描き、次のフレームに残さないことは [0019](0019-attack-volume-lifetime.md) が置き換えた。色と、判定と同じ形であることは、ここがいまの判断である。

## なぜ

攻撃したことが画面から分かるようにする。エフェクトにはしない。

## 決めたこと

攻撃を出したフレームだけ、その判定に使った、軸に沿った直方体を描く。当たったときも、空振りのときも描く。クールダウン中に Space を押しても攻撃は出ないので、ヒットボックスも出ない。

描く形は、判定に使った形と同一である。別の形や、少し大きい表示用にはしない。ヨーが世界の軸に乗っていないときも、描くのは角を含む軸に沿った直方体であり、向きを持った直方体ではない。

色はキャラクターとは別の一色 `(0.93, 0.82, 0.28)`。面ごとの色は付けない。ライティングは立方体と同じ。次のフレームには残さない。

この表示の有無と色は、描画の呼び出しとは別のファイルに置く。DirectX の型は `Renderer` の中に留める。新しい描画の手続きは `main.cpp` に足さない。

## 採らない

パーティクル。点滅。ヒットストップ。数字の飛び出し。音。向きを持った表示用メッシュ。

## あとから

残る長さは 0019 が置き換えた。色と、判定と同じ形であることは、ここから変えていない。
