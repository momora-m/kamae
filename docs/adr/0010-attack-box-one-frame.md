# 判定と同じヒットボックスを描く

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: 出現した 1 フレームのみ描画する仕様は、後続の [0019](0019-attack-volume-lifetime.md)（持続時間 3 フレーム）によって置き換えられた。判定形状と完全に同一のメッシュを描画する方針は本決定を維持する。

## なぜ

攻撃が行われたこと、およびその有効範囲がプレイヤーに視覚的に伝わるようにする。ただし演出用の派手なエフェクトではなく、デバッグや開発に適した正確な判定可視化を行う。

## 決めたこと

攻撃が発生した際、実際の当たり判定の計算に用いた AABB と完全に同一の直方体メッシュを描画する。
- 演出用に拡大縮小した別形状のメッシュは用意しない。
- キャラクターと明確に区別できる専用色（黄色系 `(0.93, 0.82, 0.28)`）で単色描画する。
- 空振り・命中にかかわらず、攻撃が発生すれば描画する。クールダウン中の無効な入力では攻撃が発生しないため、ヒットボックスも描画されない。
- ヒットボックス描画の制御コードは、DirectX 固有の型を露出させない設計を維持し、`main.cpp` に新たな描画手続きを増やさず別ファイルに切り出す。

## 採らないこと

パーティクルエフェクト、明滅やシェイク演出、画面上のダメージ数値ポップアップ、効果音。

## 後続の更新

ヒットボックスの出現持続時間（1 フレームから 3 フレームへの変更）は [0019](0019-attack-volume-lifetime.md) で改定された。
