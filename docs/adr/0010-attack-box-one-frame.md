# 攻撃したフレームだけ判定の箱を描く

- 状態: `accepted`
- 日付: 2026-09-24
- 追加: 相手の攻撃と、同じフレームの二つの箱は [0011](0011-opponent-same-attack.md)。出したフレームだけ描くことはここが現在の決定である。

## 文脈

[0009](0009-attack-reduces-remaining.md) で、ビューポートにカーソルがあるとき、Space を押したフレームにプレイヤーは自分のヨーの前方を軸に沿った箱で一度見る。重なれば相手の残りが 1 減る。空振りでも次の攻撃まで 0.4 秒空く。箱は描かない。ビューポート左上の残り数だけが変わる。

攻撃したことが画面から分かるようにする。エフェクトにはしない。

## 決定

攻撃を出したフレームだけ、その判定に使った軸沿いの箱を描く。当たったときも、空振りのときも描く。クールダウン中に Space を押しても攻撃は出ないので、箱も出ない。

描く箱は、当たり判定に使った箱と同一である。別の形や、少し大きい表示用の箱にはしない。ヨーが世界の軸に乗っていないときも、描くのは角を含む軸に沿った箱であり、向きを持った箱ではない。

箱は主体の色とは別の一色 `(0.93, 0.82, 0.28)` である。面ごとの色は付けない。ライティングは立方体と同じである。次のフレームには残さない。

パーティクル、点滅、ヒットストップ、数字の飛び出し、音は作らない。

この表示の有無と色は、描画の呼び出しとは別の翻訳単位に置く。DirectX の型は Renderer の中に留める。`main.cpp` はウィンドウ手続きと、歩行、解消、攻撃、描画の呼び出しのままである。新しい描画の手続きは `main.cpp` に足さない。

主体は [0007](0007-player-and-opponent-one-loop.md) の並びのままである。`Character` 基底や Player / Opponent 型は作らない。

相手の攻撃、硬直、ノックバック、アニメーション、勝敗の表示は含めない。

## 結果

- Space を押したフレームに、判定と同じ箱が見える。相手に当たらない位置でも見える。
- 0.4 秒より短い連打では、新しい箱は出ず、残りも減らない。
- 箱が相手に重なったときだけ残りが減る。
- 次のフレームには箱は残らない。
