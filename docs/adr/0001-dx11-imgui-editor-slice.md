# DirectX 11 と Dear ImGui で最初の画面を作る

- 状態: `accepted`
- 日付: 2026-09-23
- 言葉: [../words.md](../words.md)

## なぜ

エンジンを目指すが、最初に必要なのは触れる画面である。ウィンドウが一度も出ていないうちに仕組みを足しても、描画の壊れに気づけない。

## 決めたこと

Windows 向けの実行ファイル `editor` をひとつ作る。DirectX 11 で、光の当たる立方体をひとつ、透視カメラから描く。Dear ImGui の docking で、クリア色、カメラ距離、立方体の位置と回転を変える。ビューをドラッグすると、カメラは立方体の周りを回る。
