# DirectX 11 と Dear ImGui で最初の画面を作る

- 状態: `accepted`
- 日付: 2026-09-23
- 言葉: [../words.md](../words.md)

## なぜ

アクションゲームエンジンの開発において、最初のマイルストーンとして動作確認が可能な最小限のエディタ画面が必要である。画面描画が機能していない状態でゲームロジックを追加しても、描画の破損や不具合に気づけない。

## 決めたこと

Windows 向けの単一実行ファイル `editor` を作成する。DirectX 11 を用いてライティングされた単一の立方体を透視投影カメラから描画する。Dear ImGui（docking ブランチ）を組み込み、クリア色、カメラ距離、立方体の位置・回転を即座に変更可能とする。ビューポート上のドラッグ操作で、カメラが立方体の周囲を周回移動する。

## 採らないこと

DirectX 12、汎用エンティティ・コンポーネント構造（ECS）、物理演算、アニメーション、戦闘処理の実装。
