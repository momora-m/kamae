# DirectX 11 と Dear ImGui で最初の画面を作る

- 状態: `accepted`
- 日付: 2026-09-23

## 文脈

目指しているのはアクションゲームのエンジンです。ただし最初のマイルストーンは、遊べるゲームではなく、触れる画面です。ウィンドウが開き、立方体が見え、色と位置とカメラをその場で変えられるところまでを、この変更の完了条件にします。

画面が一度も出ていない段階で仕組みを足しても、描画が壊れていることに気づけません。

## 決定

Windows 向けの実行ファイル `editor` をひとつ作ります。DirectX 11 でライティングした立方体をひとつ、透視カメラから描きます。Dear ImGui の docking で、クリア色、カメラ距離、立方体の位置と回転を編集します。ビュー上のドラッグでカメラは立方体の周りを回ります。

この変更に DirectX 12、ECS、物理、アニメーション、戦闘は含めません。

## 結果

- 当面、エディタは Windows 専用です。Windows 10 SDK がない環境ではビルドできません。
- DirectX 12 バックエンドが必要になったら、別の ADR で決めます。この実装を黙って差し替えません。
- ゲームプレイの仕組みは、このスライスが Windows 上で実際に動くまで待ちます。
