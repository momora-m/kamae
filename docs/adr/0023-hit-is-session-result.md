# 当たりは試走が適用する結果である

- 状態: `accepted`
- 日付: 2026-09-26
- 作業: [当たりを試走が適用する結果として ADR に残す](https://github.com/momora-m/kamae/issues/69)

## 文脈

[0009](0009-attack-reduces-remaining.md) で、攻撃が届くと残りが減る。[0020](0020-subject-frame-dt.md) で、当たった主体の Δt は次のフレームから 4 フレーム 0 である。箱の寿命は [0019](0019-attack-volume-lifetime.md) のままである。箱が試走の並びにあることは [0022](0022-session-owns-volumes.md) のままである。

箱が主体に重なると、`Attack` の中で残りが減り、当たった主体の残フレームが付く。重なりと効果は同じ関数にある。

## 決定

当たりは結果である。箱は重なりを報告し、残りと残フレームは変えない。同じ箱は一つの主体を一度だけ報告する。覚えるのは箱の側である。

試走がその結果を適用する。残りは 1 減る。当たった主体の Δt は 0020 どおり、次のフレームから 4 フレーム 0 である。当たるたびに 4 フレームへ戻す。攻撃した主体は変わらない。残りが 0 の主体は対象にしない。

歩きながらの接触では当たりは出ない。箱の寿命、色、出した場所に残ることは 0019 のままである。

無敵、コンボ、新しい効果、全体ヒットストップ、ECS は含めない。数字は変えない。実装は次の issue である。

## 結果

- 箱は重なりを当たりとして出す。残りと Δt は箱の中では変わらない。
- 試走が残りを 1 減らし、当たった主体の Δt を 0 にする。
- 同じ箱は一つの主体を一度だけ報告する。
- 無敵、コンボ、新しい効果は増えない。数字も変わらない。
