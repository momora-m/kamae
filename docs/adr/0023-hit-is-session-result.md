# ヒットはプレイが適用する結果である

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [当たりを試走が適用する結果として ADR に残す](https://github.com/momora-m/kamae/issues/69)

## なぜ

ヒットボックスがキャラクターに重なると、`Attack` の中で体力が減り、当たったキャラクターの残フレームが付いていた。重なりと効果は同じ関数にある。

## 決めたこと

ヒットは結果である。ヒットボックスは重なりを報告し、体力と残フレームは変えない。同じヒットボックスは一つのキャラクターを一度だけ報告する。覚えるのはヒットボックスの側である。

プレイがその結果を適用する。体力は 1 減る。当たったキャラクターの経過秒は、次のフレームから 4 フレーム 0 である。当たるたびに 4 フレームへ戻す。攻撃したキャラクターは変わらない。体力が 0 のキャラクターは対象にしない。

歩きながらの接触ではヒットは出ない。

## 採らない

無敵。コンボ。新しい効果。全体ヒットストップ。エンティティとコンポーネント。数字の変更。
