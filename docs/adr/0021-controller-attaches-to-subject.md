# コントローラーはキャラクターに付き、同じ入力を出す

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [コントローラーが主体に付く経路を ADR に残す](https://github.com/momora-m/kamae/issues/65)

## なぜ

キーの読みと相手の接近が、同じ入力の出し手になっていない。着脱する画面の話ではない。

## 決めたこと

コントローラーはキャラクターに付く。最初の二つは、プレイヤーのキーと相手の接近である。どちらも水平の歩きと、攻撃する／しないを出す。

プレイは、その入力から `WalkCube` と `Attack` を呼ぶ。相手の接近は歩きと `Attack` を直接呼ばない。`WalkCube` と `Attack` は、添字 0 を特別扱いしない。間隔と先行入力は、コントローラーが渡す値である。プレイヤーは今どおり 0.4 秒と先行入力、相手は今どおり 0.8 秒で先行入力は無い。

カメラの注視点と、全滅でプレイを止める判定は、先頭のキャラクターのままである。ここは歩きと攻撃の話ではない。

## 採らない

パッド。リバインド。エンティティとコンポーネント。コントローラーの GUI。新しい相手の状態。ヒットボックスの並びの切り出し。ヒットの適用の切り出し。数字の変更。
