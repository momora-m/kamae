# 試走の攻撃を、プレイヤーが先に当てられる間隔にする

- 状態: `accepted`
- 日付: 2026-09-26
- 作業: [試走を勝てるように、プレイヤーの先行入力と相手の攻撃間隔を分ける](https://github.com/momora-m/kamae/issues/47)

## 文脈

[0011](0011-opponent-same-attack.md) で、相手は攻撃の箱がプレイヤーに重なる距離で立ち止まり、プレイヤーと同じ攻撃を 0.4 秒に一度出す。開始時のクールダウンは 0 なので、重なった最初のフレームに相手が撃つ。その後も同じ間隔である。[0009](0009-attack-reduces-remaining.md) のプレイヤーも次の攻撃まで 0.4 秒空ける。残りはどちらも 3 である。クールダウン中の Space は捨てる。Space は、ビューポートにカーソルがあり、文字入力がキーを取っていないときだけ届く。

同じ間隔で相手が先に撃つので、プレイヤーは先に当てて試走を終えられない。間合いは [0015](0015-edit-then-start-a-trial.md) の初期位置で空いている。攻撃の溜めでは空けない。

## 決定

プレイヤーの攻撃間隔は 0.4 秒のままである。相手の繰り返しは 0.8 秒である。相手の最初の一発は、攻撃の箱がプレイヤーに重なってから 0.5 秒待って出す。この待ちは、範囲に入ったときに始まる。開始を押したときには始めない。範囲を外れたら待ちは消え、次に入ったときにまた 0.5 秒待つ。待ちのあいだは歩かず、ヨーは 0011 のままプレイヤーへ向ける。待ちが終わったあとに範囲へ居続けるあいだは、直前の攻撃から 0.8 秒ごとに出す。0.5 秒は、その居続きの最初の一発の前だけである。

プレイヤーの Space は、クールダウンの最後の 0.15 秒だけ覚える。それより前の押下は捨てる。そのフレームでクールダウンを減らしたあと、残りが 0 より大きく 0.15 秒以下なら覚える。クールダウンが 0 になったフレームに、覚えがあるか、そのフレームに新しく押したなら、一度だけ出す。覚えは一度出すと消える。押し続けの繰り返しは見ない。これは先行入力であり、攻撃の溜めではない。出るまでの溜め動作は足さない。

箱の大きさは [0015](0015-edit-then-start-a-trial.md) と [0009](0009-attack-reduces-remaining.md) のまま、前方 1.0、左右は中心から 0.5 である。残りは 3 から始まる。Space は、ビューポートにカーソルがあり、文字入力がキーを取っていないときだけである。試走の開始と停止は 0015 のままである。箱が残る長さは [0019](0019-attack-volume-lifetime.md) が決める。覚えた押下のフレームには箱を出さない。出したフレームに出す。

攻撃の溜め、無敵時間、コンボは 0015 のまま採らない。溜めは後に回すのではなく、採らない。

## 結果

- 相手は間合いに入ったフレームでは撃たない。0.5 秒待ってから最初の一発を出す。居続けるあいだは、その後 0.8 秒ごとである。
- プレイヤーは 0.4 秒ごとである。終わり 0.15 秒の Space は、クールダウンが 0 になったフレームに一度出る。それより前の Space は捨てる。
- 溜め、無敵、コンボは増えない。箱の大きさと、試走の開始と停止は変わらない。
