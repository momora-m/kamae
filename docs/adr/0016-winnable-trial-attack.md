# プレイヤーが先に当てられる間隔にする

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [試走を勝てるように、プレイヤーの先行入力と相手の攻撃間隔を分ける](https://github.com/momora-m/kamae/issues/47)

## なぜ

[0011](0011-opponent-same-attack.md) ではプレイヤーも敵も同一の攻撃間隔（0.4 秒）かつ開幕クールダウン 0 であったため、間合いに入った瞬間に必ず敵が先制攻撃を繰り出し、プレイヤーが勝てない構造になっていた。攻撃前の溜め動作を設けずに、プレイヤーが有利に立ち回れるタイミング設計を行う。

## 決めたこと

プレイヤーと敵の攻撃パラメータを差別化する：
- **敵の攻撃タイミング**:
  - 間合いに入った直後は即座に攻撃せず、**初撃のみ 0.5 秒の待機時間** を設ける。
  - 待機中に間合いの外へ離脱された場合、待機タイマーは破棄され、再進入時に再度 0.5 秒待機する。
  - 間合い内に留まり続けた場合の 2 撃目以降の攻撃間隔は **0.8 秒** とする。
- **プレイヤーの先行入力受付**:
  - プレイヤーの攻撃クールダウン（0.4 秒）の終了直前 **0.15 秒間に入力された Space キーをバッファに記憶** する。
  - クールダウンが 0 に到達したフレームにバッファ入力または新規入力があれば、即座に次の攻撃を発生させる（先行入力は消費される）。長押しによる自動連射は無効。
  - これにより、目押し入力のブレによる隙をなくし、最速で連続攻撃を繰り出せるようにする。

## 採らないこと

攻撃発生前の溜めアニメーション、被弾無敵時間、連続コンボシステム、ヒットボックス寸法の変更。
