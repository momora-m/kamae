# プレイヤーが先に当てられる間隔にする

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [試走を勝てるように、プレイヤーの先行入力と相手の攻撃間隔を分ける](https://github.com/momora-m/kamae/issues/47)

## なぜ

同じ間隔で相手が先に撃つので、プレイヤーは先に当ててプレイを終えられない。間合いは初期位置で空いている。攻撃の溜めでは空けない。

## 決めたこと

プレイヤーの攻撃間隔は 0.4 秒のままである。相手の繰り返しは 0.8 秒である。相手の最初の一発は、攻撃のヒットボックスがプレイヤーに重なってから 0.5 秒待って出す。この待ちは、範囲に入ったときに始まる。開始を押したときには始めない。範囲を外れたら待ちは消え、次に入ったときにまた 0.5 秒待つ。待ちのあいだは歩かず、ヨーはプレイヤーへ向ける。待ちが終わったあとに範囲へ居続けるあいだは、直前の攻撃から 0.8 秒ごとに出す。0.5 秒は、その居続きの最初の一発の前だけである。

プレイヤーの Space は、クールダウンの最後の 0.15 秒だけ覚える。それより前の押下は捨てる。そのフレームでクールダウンを減らしたあと、クールダウンがまだ 0 より大きく 0.15 秒以下なら覚える。クールダウンが 0 になったフレームに、覚えがあるか、そのフレームに新しく押したなら、一度だけ出す。覚えは一度出すと消える。押し続けの繰り返しは見ない。これは先行入力であり、攻撃の溜めではない。出るまでの溜め動作は足さない。

Space は、ビューポートにカーソルがあり、文字入力がキーを取っていないときだけである。覚えた押下のフレームにはヒットボックスを出さない。出したフレームに出す。

## 採らない

攻撃の溜め。無敵時間。コンボ。ヒットボックスの大きさの変更。
