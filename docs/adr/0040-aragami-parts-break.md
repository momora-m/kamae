# 大きい相手の部位を壊してから本体を倒す

- 状態: `accepted`
- 日付: 2026-10-02
- 言葉: [../words.md](../words.md)
- 作業: [自分より大きいアラガミの部位を壊しながら倒す](https://github.com/momora-m/kamae/issues/116)

## なぜ

相手はプレイヤーと同じ半辺 0.5 で、当たる場所は本体の立方体だけだった。自分より大きい相手を、部位を壊しながら倒すには、大きさと、本体とは別の壊せる箇所が要る。部位のために新しいメッシュや、壊れたあとのラグドールを足すと、今の一色メッシュとヒットボックスの寿命から外れる。同じメッシュを拡大し、壊せる箇所はヒットボックスと同じ立方体の描き方で少数だけ足す。変わるのは当てられる場所であり、接近や歩く速さは今のままにする。

## 決めたこと

プレイヤーの大きさは変えない。半辺は 0.5 のままである。初期の相手 1 人を、プレイヤーより大きい一体にする。追加した相手も同じ大きさである。0 人から 3 人の増減は変えない。

- **大きさ**:
  - 相手の半辺は 1.0 とする。プレイヤーの 2 倍である。
  - 中心の Y は 0.5 とする。底が Y = -0.5 で、プレイヤーの立方体の底と揃う。追加した相手も同じ高さから始まる。コード上の初期位置は `(0, 0.5, 4)` である。
  - 床への接地は、その半辺の底で見る。プレイヤーは今どおり中心 Y = 0 である。
  - 見た目は同じ `assets/character.gltf` を、半辺の比 2 で拡大して描く。読めないときの立方体も同じ比で拡大する。新しいメッシュファイルは足さない。色はキャラクターごとに一色のままである。
  - 歩行の障害と、本体の重なりは、この半辺の立方体である。ヨーはこの立方体に効かない。
  - 相手の技のヒットボックスは、その半辺 1.0 の前面から伸びる。プレイヤーの技は半辺 0.5 の前面のままである。
  - シーンには大きさを書かない。読み込んだ相手も半辺 1.0 にする。読み込んだ Y が 0.5 より低いときは 0.5 まで上げ、底が床より下に残らないようにする。0.5 より高い Y はそのままにする。
  - 規定の間隔 4 では、刃の短い技と長い技と捕食は本体に届かない。銃は届く。
- **部位**:
  - 相手は部位を 2 つ持つ。プレイヤーは持たない。
  - 各部位の耐久は 1 である。重なって減る量は 1。0 になると壊れ、描かず、重なりの対象にしない。
  - 部位は軸平行の立方体で、半辺 0.30 である。ヨーでは回さない。本体の立方体と同じく、ヨーは部位の立方体に効かない。
  - 前の部位は、相手の中心から Z を -1.15 ずらす。半辺 0.30 と合わせて、本体の前面（半辺 1.0）より -Z へ出る。左右のずれは 0、Y のずれは -0.15 である。
  - 横の部位は、中心から X を 1.15 ずらす。半辺 0.30 と合わせて、本体の側面より +X へ出る。Z のずれは 0、Y のずれは -0.15 である。
  - Y のずれ -0.15 は、相手の中心 Y 0.5 と合わせて、プレイヤーの技の高さ（中心 0、半辺 0.5）に重なるようにするためである。
  - 規定の間隔 4 で、プレイヤーが原点、相手が Z = 4 のとき、正面の銃は前の部位に重なり、横の部位には重ならない。長い技と捕食は、その位置では前の部位にも届かない。横の部位は、プレイヤーが +X へ寄ると、刃、銃、捕食のどれでも重なり得る。
  - 見た目はヒットボックスと同じ立方体の描き方で、色は `(0.95, 0.55, 0.22)` とする。キャラクターの一色や、刃と銃のヒットボックスや、捕食のヒットボックスとは別である。壊れた部位は描かない。編集中も、残っている部位は描く。
  - 部位は歩行の障害にしない。障害は本体の立方体だけである。
  - シーンと開始状態には部位の耐久を書かない。開始、やり直し、編集への復帰、シーンの読み込み、初期配置へのリセットでは、両方とも 1 に戻す。
- **壊れたあとに変わること**:
  - 変わるのは、当てられる場所である。壊れた部位の立方体は消え、そこには重ならなくなる。
  - 接近、横移動、後退、技の選択、歩く速さは変えない。
- **本体の倒し方**:
  - 部位が一つでも残っているあいだ、本体の立方体に重なっても体力は減らない。ヒットストップも当たった力も置かない。
  - そのフレームの開始時に全部位が既に壊れているときだけ、本体への重なりは今どおり体力を 1 減らし、ヒットストップと当たった力を置く。
  - 同じフレームで最後の部位が壊れても、そのフレームの本体は減らない。次のヒットから本体が対象になる。
  - 刃、銃、捕食のどれでも、重なった部位の耐久を 1 減らす。回避中と正面のガードでは減らさない。横と後ろは減らす。同じヒットボックスは、一つの部位を一度だけ見る。防いでも、その部位はもう見ない。
  - 捕食は、そのヒットで部位の耐久を減らしたとき、弾を 1 戻す。全部位が壊れたあと、本体に重なったときも 1 戻す。部位が残っていて本体にだけ重なったときは戻さない。空振りでは戻さない。上限は 3 のままである。捕食は本体の体力を減らさない。
  - 一人の部位が複数壊れても、そのキャラクターについて戻す弾は 1 である。複数のキャラクターに同時に成立したときは、成立した人数だけ戻し、上限で止める。
  - 体力が 0 の相手は描かず、歩行の障害にも、攻撃の対象にも、部位の対象にもしない。使っている相手が全員 0 のときは、大きい相手でもプレイを止める。

## 採らないこと

物理ライブラリ、ECS、描画 API の変更、部位破壊のラグドール、新しいメッシュ、アニメーション、部位ごとに動きを変えること、プレイヤーの拡大、部位を 3 つ以上にすること、部位をパネルから編集すること、ミッション、編成、バースト。
