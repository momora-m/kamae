# 近い捕食で弾を戻す

- 状態: `accepted`
- 日付: 2026-10-02
- 言葉: [../words.md](../words.md)
- 作業: [相手の近いところで捕食すると、弾が戻る](https://github.com/momora-m/kamae/issues/115)

## なぜ

銃は弾を消費するが、[0038](0038-god-arc-switches-blade-and-gun.md) では戻す手段を置かなかった。弾が 0 になると、刃より遠い攻撃はそこで終わる。斬る、撃つ、近づいて食って弾が戻る、を一周させるには、相手の近いところでだけ成立する捕食が要る。捕食のために別の判定を新設すると、発生・持続・硬直と、同じ相手に一度だけの扱いが二重になる。プレイセッションが既に持つヒットボックスの寿命に乗せ、届く距離と、重なったときの結果だけを変える。

## 決めたこと

プレイヤーだけが捕食する。相手は出さない。刃と銃のどちらでも出せる。弾が 0 でも出せる。捕食は体力を減らさない。

- **入力**:
  - キーは C とする。WASD、Space、F、Shift、Q、E、R、G は変えない。
  - 押したフレームに一度出す。押し続けても、そのあとのフレームでは出ない。
  - 同じフレームで C と Space、F、G のいずれかが押されたときは、捕食だけを受け付ける。刃の技も銃も出さず、弾も減らない。
  - 床に着いているフレームで E と C が同時のときは、回避だけを受け付ける。捕食は出ない。回避の途中も捕食は出ない。空中では回避が出ないので、そのフレームの C は捕食として見る。これは、空中で回避と技のキーが同時のときに技が出る今の規則と同じである。
  - 同じフレームで R と C が押されたときは、先に形態を切り替えてから捕食を受け付ける。刃と銃のどちらへ切り替わっても捕食は出る。同じフレームで E と R が押されたときは、今どおり回避だけを受け付け、形態は変えない。
  - ガード中は新しい技と同じく出ない。発生と硬直の途中ではガードは始まらない。
  - ヒットストップでフレーム更新時間が 0 のフレームは、クールダウンが 0 で、発生も硬直も残っていなければ、経過時間が 0 でも捕食の番号は通る。形態の切り替えは、経過時間が 0 のフレームでは行わない。
  - 先行入力は、クールダウンの最後 0.15 秒だけ、最後の一つを覚える。捕食もこの規則に入る。
- **技**:
  - 技テーブルへ捕食の行（`kMoveDevour`）を足す。前方 0.6、左右は中心から 0.5、次まで 0.6 秒とする。
  - 前方 0.6 は短い技の 1.0 より短い。ヒットボックスは半辺 0.5 の前面から伸び、共有する面だけでは重ならない。規定の間隔 4 では、短い技も捕食も相手に重ならない。重なるには、相手の立方体へ近づく。左右は刃と同じ 0.5 のままにする。変えるのは届く距離だけである。
  - 発生 1 フレーム、持続 3 フレーム、硬直 1 フレームは刃と同じである。
  - 発生と硬直のあいだは歩けず、新しい技も出ない。持続中の歩行は止めない。受け付け済みの捕食は、形態を切り替えても進む。
  - ヒットボックスはプレイセッションの配列に出す。判定と描画は同じ区間を見る。色は刃と銃のヒットボックスとは別の `(0.42, 0.74, 0.38)` とする。寿命の規則は同じである。
  - クールダウンはキャラクターに一つである。捕食のあと、その間隔が残っているあいだは刃の技も銃も出ない。先行入力は、出すフレームの形態で出せない技を捨てる。捕食は形態では捨てない。
- **弾**:
  - 戻す量は 1 とする。銃を受け付けたときに 1 減ることと対になる。
  - 戻すのは、捕食のヒットボックスが体力のある他のキャラクターに重なり、そのキャラクターが回避中でなく、正面のガードでも防いでいないときだけである。
  - 空振りでは戻さない。回避中と正面のガードでは戻さない。横と後ろから重なったときは戻す。防いだ相手も、そのヒットボックスはもう見ない。
  - 同じヒットボックスは、一つのキャラクターについて一度だけ戻す。複数に重なったときは、成立した人数だけ戻し、上限で止める。
  - 上限は開始時の 3 である。3 を超えない。既に 3 のときは、重なっても 3 のままである。
  - 捕食は体力を減らさず、ヒットストップも置かず、当たった力も足さない。
  - シーンと開始状態には弾を書かない。開始、やり直し、編集への復帰、シーンの読み込みでは 3 に戻す。パネルからは変えない。ビューポートと Subjects では読むだけである。

## 採らないこと

アラガミの部位、自分より大きい相手、相手が捕食すること、捕食で体力を減らすこと、ヒットボックス以外の判定、弾や捕食をパネルから編集すること、物理ライブラリ、描画 API の変更、ECS、新しいメッシュ。
