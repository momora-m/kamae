# 配置ファイルの行を決める

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: 単一ファイル `arena.txt` への直接保存および起動時の自動読み込み仕様は、後続の [0015](0015-edit-then-start-a-trial.md)（名前付きシーンファイル複数保存）によって置き換えられた。ファイルフォーマットの行定義は本決定を維持する。

## なぜ

エディタ上で調整したアリーナの配置（床サイズやキャラクターの初期位置）をファイルとして永続化し、アプリ再起動後も同じ環境を再現できるようにする。

## 決めたこと

プレーンテキストによる最小限のファイル行形式を定義する（外部シリアライズライブラリは導入しない）：
- `floor <half_extent>`: 床板の半辺（4.0 〜 40.0、規定値 20.0）。外壁の位置もこの半辺に連動する。
- `<x> <y> <z> <yaw> <r> <g> <b>`: キャラクターの配置情報。先頭行がプレイヤー、後続行が敵キャラクターを表す。
- 体力、攻撃クールダウン、カメラパラメータ、クリア色などの過渡的な状態はファイルに書き出さない。読み込み時の体力は 3、クールダウンは 0 に初期化される。
- 書式不正、数値の欠損、半辺が範囲外、キャラクター数が 0 または 5 体以上の場合は読み込みを拒絶し、現在の配置を維持したまま UI にエラーを通知する。

## 採らないこと

戦闘中の途中経過（体力残量等）のセーブ、アンドゥ・リドゥ機能、外壁の個別配置データ、メッシュや音声等のアセットロード。

## 後続の更新

保存先を単一固定ファイルから `scenes/` ディレクトリ配下の名前付きファイル群へ変更し、起動時自動ロードを廃止した仕様は [0015](0015-edit-then-start-a-trial.md) で改定された。
