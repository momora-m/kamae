# 配置ファイルの行を決める

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: `arena.txt` 一つへの上書きと、起動時にそのファイルを読むことは [0015](0015-edit-then-start-a-trial.md) が置き換えた。行の種類は、ここがいまの判断である。

## なぜ

同じルールのアリーナを、C++ を変えずに残す。戦闘の途中経過は保存しない。

## 決めたこと

保存する行は次だけである。新しいライブラリは入れない。

- `floor` と、床の半辺
- キャラクターの行。順に、位置の X Y Z、ヨー、色の R G B。先頭の行がプレイヤーである

残り、攻撃のクールダウン、ピッチ、ロール、カメラ、クリア色は書かない。読み込んだキャラクターの残りは 3、クールダウンは 0、ピッチとロールは 0。

床の半辺はパネルで変える。範囲は 4 以上 40 以下。既定は 20。壁は、その半辺の縁から作る。個別の壁は置かない。床の板は、同じ半辺になるよう XZ だけを拡縮する。

行が足りない、数が読めない、数が有限でない、床の半辺が 4 未満か 40 を超える、色の成分が 0 未満か 1 を超える、キャラクターが 0 人または 5 人以上、行の形が違うときは、読み込まない。今の配置を保ち、失敗を出す。空の行は無視する。

当時は、作業ディレクトリの `arena.txt` 一つに書き、パネルに Save と Load を置き、起動時にファイルがあれば Load と同じ置き換えをすると書いた。ファイルが無ければコードの初期配置のまま始め、失敗は出さない。Load を押したときにファイルが無いのは失敗である。

読み書きは `main.cpp` とは別のファイルに置く。

## 採らない

複数スロット。戦闘中の残りのセーブ。アンドゥ。壁を一本ずつ置くこと。メッシュや音声の読み込み。`Character` 基底。シーン階層。アセットパイプライン。

## あとから

ファイルの場所と、起動時に読むことは 0015 が置き換えた。行の種類と、壊れたファイルを拒否することは、ここから変えていない。
