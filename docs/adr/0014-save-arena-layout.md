# アリーナの初期配置を保存して起動時に読み戻す

- 状態: `accepted`
- 日付: 2026-09-24

## 文脈

[0012](0012-edit-subject-pose.md) と [0013](0013-add-remove-opponents.md) で、パネルは主体の位置とヨーを編集し、相手を 0 人から 3 人まで増減できる。床の半辺は 20 で、壁はその縁にある。再起動するとコードに書いた配置に戻る。

同じルールのアリーナを、C++ を変えずに残す。戦闘の途中経過は保存しない。

## 決定

保存するファイルは作業ディレクトリの `arena.txt` 一つである。新しいライブラリは入れない。行は次だけである。

- `floor` と、床の半辺
- 主体の行。順に、位置の X Y Z、ヨー、色の R G B。先頭の行がプレイヤーである

残り、攻撃のクールダウン、ピッチ、ロール、カメラ、クリア色は書かない。読み込んだ主体の残りは 3、クールダウンは 0、ピッチとロールは 0 である。

床の半辺はパネルで変える。範囲は 4 以上 40 以下である。既定は 20 である。壁は今までどおり、その半辺の縁から作る。個別の壁は置かない。床の板は、同じ半辺になるよう XZ だけを拡縮する。

パネルに Save と Load を置く。Save は今の床の半辺と、使っている主体の行を書く。Load はそのファイルで床の半辺と主体の配置を置き換える。起動時にファイルがあれば Load と同じ置き換えをする。ファイルが無ければ、コードの初期配置のまま始め、失敗は出さない。Load を押したときにファイルが無いのは失敗である。

行が足りない、数が読めない、数が有限でない、床の半辺が 4 未満か 40 を超える、色の成分が 0 未満か 1 を超える、主体が 0 人または 5 人以上、行の形が違うときは、読み込まない。今の配置を保ち、パネルに失敗を出す。空の行は無視する。

読み書きは別の翻訳単位に置く。`main.cpp` は起動時の呼び出しだけを足す。`Character` 基底、シーン階層、アセットパイプラインは作らない。

複数スロット、戦闘中の残りのセーブ、アンドゥ、壁を一本ずつ置くこと、メッシュや音声の読み込みは含めない。

## 結果

- 相手を足し、位置と床の半辺を変えて Save すると、再起動しても同じ配置になる。残りは 3 から始まる。
- ファイルを消すと、コードの初期配置で始まる。
- 壊したファイルでは配置が変わらず、パネルに失敗が出る。
- ファイル一つへの上書きと、起動時にそのファイルを読んで試走を始めることは [0015](0015-edit-then-start-a-trial.md) が置き換える。シーン一つの行の種類は、ここから変えない。
