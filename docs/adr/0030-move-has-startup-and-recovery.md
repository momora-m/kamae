# 技には発生と硬直がある

- 状態: `accepted`
- 日付: 2026-09-27
- 言葉: [../words.md](../words.md)
- 作業: [技には発生と硬直がある](https://github.com/momora-m/kamae/issues/97)

## なぜ

技テーブルの各行はリーチと攻撃間隔だけを持ち、発生 0 フレーム、持続 3 フレーム、硬直 0 フレームで固定されていた。入力を受け付けたフレームにヒットボックスが出て、そのあいだも歩行できる。クールダウン中は新しいヒットボックスは出ないが、出したあとに歩行も次の技も止まる区間がない。一試合のリリースでは、技を出したあとに発生と硬直で隙ができるようにする。その最初の一片として、技テーブルの各行へ発生と硬直を持たせ、持続中だけヒットボックスを出す。

## 決めたこと

技テーブルの各行に、発生、持続、硬直のフレーム数を持たせる。プレイヤーと相手は同じ表を見る。

- **フレーム数**:
  - 短い技と長い技は、どちらも発生 1 フレーム、持続 3 フレーム、硬直 1 フレームとする。
  - 発生 1 と硬直 1 は、短い技の攻撃間隔 0.4 秒と相手の初撃待機 0.5 秒を崩さない最小の正のフレーム数である。
  - ダメージ 1 と、被弾時の 4 フレーム個別ヒットストップは変えない。
- **進行**:
  - プレイセッションは、技の番号を受け付けたフレームから、その行の発生、持続、硬直を順に進める。
  - 発生が終わったフレームから、持続 3 フレームのあいだヒットボックスを出す。判定と描画は同じヒットボックスを見る。
  - 発生・持続・硬直はプレイのフレームで数え、ヒットボックスの寿命と同じく、フレーム更新時間には束縛されない。クールダウンはこれまでどおりフレーム更新時間で減る。
- **歩行と次の技**:
  - 発生のあいだと硬直のあいだは、そのキャラクターは歩けない。新しい技も出ない。
  - 持続中の歩行は止めない。
  - クールダウンは、技を受け付けたフレームからその行の間隔だけ進む。
  - 先行入力は、クールダウンの最後 0.15 秒だけ、最後に押した技の番号を覚える。硬直中の押下もこの規則のまま扱う。
  - 覚えた押下のフレームにはヒットボックスを出さない。発生と硬直が残っているフレームには、クールダウンが 0 でも新しい技は出ない。
- **相手**:
  - 接近、間合い待ち、後退の規則は変えない。後退の歩行は、発生と硬直で歩けないフレームだけ止まる。
- **開始と復帰**:
  - プレイの開始、再開、編集モードへの復帰では、発生・持続・硬直の進行を消す。

## 採らないこと

ガード、押し出し、速度、物理ライブラリ、アニメーション、技の追加、ダメージの変更。技ごとに発生や硬直を変えること、発生中の無敵、硬直のキャンセルも採らない。
