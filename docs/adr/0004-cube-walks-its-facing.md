# 立方体は自分の向きに歩く

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)

## なぜ

[0003](0003-cube-walks-on-ground.md) では、カメラを回すと進行方向が変わる。向きをパネルで保っておけない。歩く担当と、それを見るカメラを分ける。

## 決めたこと

0003 のうち、次の二つを置き換える。本文は残し、ここがいまの判断である。

- 進行方向はカメラのヨーではなく、立方体のヨー（当時の `cube_rotation_degrees` の Y）である。
- 歩行はヨーを上書きしない。向きを変えるのは、パネルの回転だけである。

ビューポートにカーソルがあるとき、WASD で XZ を動かす。W はそのヨーの向き、S は逆、D はその右、A は左。A と D だけでその場回転はしない。斜め入力は速さを増やさない。カメラを回しても進行方向は変わらない。

## 採らない

当たり判定。アニメーション。二体目。入力の抽象化。コンポーネント一覧。コントローラーを付ける画面。

## あとから

カメラの水平ヨーで歩く切り替えは [0005](0005-walk-along-camera-yaw.md)。既定はこのままである。
