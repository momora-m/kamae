# 立方体は自分の向きに歩く

- 状態: `accepted`
- 日付: 2026-09-24
- 追加: カメラの水平ヨーで歩く任意のモードは [0005](0005-walk-along-camera-yaw.md)。既定はこのままである。

## 文脈

[0003](0003-cube-walks-on-ground.md) では、WASD の前後左右はカメラが見ている水平方向で、歩いているあいだヨーは移動方向を向きます。カメラを回すと進行方向が変わり、向きをパネルで保っておけません。

歩く担当と、それを見るカメラを分けます。後からキャラクターコントローラーを付けられるようにするための、次の一塊です。

## 決定

0003 のうち、次の二つを置き換えます。本文は残し、ここが現在の決定です。

- 進行方向はカメラのヨーではなく、立方体のヨー（`cube_rotation_degrees` の Y）です。
- 歩行はヨーを上書きしません。向きを変えるのは、パネルの回転だけです。

ビューポートにカーソルがあるとき、WASD で立方体を XZ 平面上で動かします。W はそのヨーの向き、S は逆です。D はその右、A は左です。A と D でその場回転はさせません。斜め入力は正規化し、速さは増やしません。カメラを回しても進行方向は変わりません。

速さは秒あたり 2.5、経過時間の上限は 0.1 秒、Y は変えない、のままです。カメラは今の球面のまま、立方体の位置を見続けます。

当たり判定、アニメーション、二体目のメッシュ、入力の抽象化、コンポーネントの一覧、コントローラーを付ける GUI は含めません。

## 結果

- 位置と回転は、これまでどおり `SceneState` の立方体の値です。歩いているフレームも、ヨーはパネルの値のままです。
- 床、カメラの周回、速さは 0003 のままです。
