# 二つ目の技は、届く距離が長く、次までも長い

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [二つ目の技は、届く距離が長く、次までも長い](https://github.com/momora-m/kamae/issues/87)

## なぜ

技テーブルが単一の突き攻撃のみであったため、間合いの長短に応じた選択肢がなく、プレイヤーも敵も常に画一的な近接戦を強いられていた。リーチが長く隙の大きい二つ目の技を追加することで、間合いに応じた立ち回りと駆け引きを成立させる。

## 決めたこと

[0026](0026-action-picks-a-move.md) で導入した技テーブルへ二つ目の技（`kMoveLong = 2`）を追加し、以下の仕様を決定する。

- **技パラメータの差別化**:
  - **強攻撃（長距離技）**: 前方リーチ 2.0、左右幅 0.5、攻撃間隔（クールダウン）1.0 秒。
  - **弱攻撃（突き技）**: [0026](0026-action-picks-a-move.md) のとおり前方リーチ 1.0、左右幅 0.5、攻撃間隔 0.4 秒を維持。
  - 発生 0 フレーム、持続 3 フレーム、硬直 0 フレーム、ダメージ 1、および被弾時の 4 フレーム個別ヒットストップは両技共通とする。
  - 規定の初期配置における両者の間隔（4.0）では、どちらの攻撃も届かない。
- **プレイヤーの操作**:
  - Space キーで弱攻撃、F キーで強攻撃を繰り出す。
  - 同一フレームで両キーが同時に押下された場合は、強攻撃（F キー）を優先して受け付ける。
  - クールダウン終了前 0.15 秒間の先行入力バッファは、最後に押下された技 ID のみを保持する。
- **敵 AI の技選択ロジック**:
  - 弱攻撃の間合いに入っている場合は、弱攻撃を選択する。
  - 弱攻撃は届かないが強攻撃なら届く間合いにいる場合のみ、強攻撃を選択して間合い待ちを開始する。
  - 間合い待ちの途中で対象の距離が変化して選択技が切り替わった場合、その技に対する初撃待機時間（0.5 秒）を改めて最初からカウントする。
  - 攻撃後の後退挙動は、自身が直前に繰り出した技のヒットボックスが交差解消するまで実行する。

## 採らないこと

三つ目以降の技、攻撃前の溜め動作、被弾無敵時間、技キャンセルや連続コンボ、技ごとのダメージやヒットストップの個別化。
