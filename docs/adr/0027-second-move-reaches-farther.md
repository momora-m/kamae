# 二つ目の技は、届く距離が長く、次までも長い

- 状態: `accepted`
- 日付: 2026-09-26
- 言葉: [../words.md](../words.md)
- 作業: [二つ目の技は、届く距離が長く、次までも長い](https://github.com/momora-m/kamae/issues/87)

## なぜ

技の表は一行だけだった。届く距離が違う攻撃がないと、間合いを変えても出す技は同じになる。二つ目の行は、最初の行より遠くに届き、次に出すまでも長くする。発生、持続、硬直、ダメージ、ヒットストップは分けない。

## 決めたこと

二つ目の行は、前方 2.0、左右は中心から 0.5、次まで 1.0 秒である。最初の行は前方 1.0、左右 0.5、次まで 0.4 秒のままである。発生 0 フレーム、持続 3 フレーム、硬直 0 フレーム、ダメージ 1、ヒットストップ 4 フレームは、どちらの行も同じである。組み込みの間隔 4 では、どちらのヒットボックスも届かない。長い行が届くのは、向きの軸上で中心の間隔が 3 より短いときである。

プレイヤーは Space で最初の行を、F で長い行を出す。同じフレームで両方押したときは、長い行を出す。0.15 秒の先行入力は、最後に押した技の番号だけを覚える。

相手は、短い行が届かず長い行が届くときだけ、長い行を選ぶ。短い行が届くときは短い行である。選んだ行が待ちの途中で変わったら、その行の初撃は重なってから 0.5 秒待つ。クールダウンが残っているあいだは撃たず、0 になってから出す。後退は、今出した行のヒットボックスがプレイヤーに重ならなくなるまでである。それ以外の後退の規則は変えない。

## 採らないこと

三つ目の技、溜め、無敵、コンボ、技ごとのダメージ差、技ごとのヒットストップ差。発生・持続・硬直を行ごとに変える理由は、まだない。
