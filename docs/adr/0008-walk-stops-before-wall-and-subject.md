# 歩行は壁と他のキャラクターの手前で止まる

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: [0006](0006-walk-stops-at-floor-edge.md) の数値範囲直接クランプ処理を、本 ADR の軸別衝突判定および外壁による境界処理で置き換える。

## なぜ

単に座標を数値で切り詰めるだけでは、ステージの外壁が存在しないため視覚的に不自然であり、また追加された敵キャラクターの体をすり抜けてしまう。落下や重力計算を入れずに、壁や障害物の手前で自然に停止させたい。

## 決めたこと

ステージ外周（`X, Z = ±20`）に、視認可能な静止した外壁オブジェクト（厚み 1、高さ 2）を配置する。壁の色はキャラクターと明確に区別できる単色とする。

移動衝突の解消方式として、軸別の移動取り消し（スライド移動）を採用する：
1. 移動ベクトルに基づき、まず X 軸方向へ移動を適用する。
2. 壁または自分以外の生存キャラクターとのバウンディングボックス（AABB）が交差した場合、X 軸の移動のみを取り消す。
3. 次に Z 軸方向へ移動を適用し、同様に衝突した場合は Z 軸の移動のみを取り消す。
4. Y 座標は変化させない。斜め移動で衝突した場合、衝突していない軸の移動成分のみが有効となり、壁沿いに滑らかにスライドする。
5. 複雑な反発力計算やめり込みの押し出し処理は行わない。

## 採らないこと

剛体物理シミュレーション、速度ベクトルの累積、加速度、ナビゲーションメッシュ、傾斜面対応。

## 後続の更新

敵キャラクターの移動時にも同一の衝突解消ロジックを適用する決定は [0011](0011-opponent-same-attack.md) で行われた。
