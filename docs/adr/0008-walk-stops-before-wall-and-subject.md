# 歩行は壁と他のキャラクターの手前で止まる

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: [0006](0006-walk-stops-at-floor-edge.md) の ±19.5 への固定を、この解消に置き換える。

## なぜ

アリーナは閉じている。床の数字で位置を切り詰めるだけでは、壁も他のキャラクターもすり抜ける。落下と重力はこの判断に入れない。

## 決めたこと

床の縁 `x, z = ±20` に、動かない壁の内面を置く。壁は見える直方体である。厚みは 1、高さは 2、底はキャラクターの底と同じ `Y = -0.5`。±X の壁は角を含めて Z を外側まで覆う。±Z の壁は、内面のあいだの X だけを覆い、外へ同じ厚みだけ出る。壁の色は一色で、キャラクターの色とは分ける。面ごとの色は付けない。

キャラクターの半辺は 0.5。重なりは軸に沿った直方体で見る。ヨーによる角のはみ出しは詰めない。

歩行が X と Z を動かしたあと、先に X だけ動かした位置を見る。壁か、自分以外のキャラクターに重なったら、X の移動だけ取り消す。つぎに Z で同じことをする。面へ寄せない。押し出しの連鎖や反発はしない。Y は変えない。

重ならない中心は、壁の内面から半辺だけ内側に残る。

歩いていないフレームでは、すでに重なっている位置を押し出さない。パネルで壁や他のキャラクターの中へ置いたとき、結果が重ならない軸の移動だけが残る。

当時、歩くのはプレイヤーだけと書いた。相手は動かない。プレイヤーが相手へ歩くと、相手の手前で止まる。

## 採らない

重力。落下。剛体。速度の蓄積。斜面。段差。ナビメッシュ。攻撃。外部の物理ライブラリ。種類や基底を足すこと。

## あとから

相手も歩き、同じ解消を使うことは [0011](0011-opponent-same-attack.md)。壁が半辺の縁にあることは、ここから変えていない。
