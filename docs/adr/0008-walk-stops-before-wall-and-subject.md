# 歩行は壁と相手の手前で止まる

- 状態: `accepted`
- 日付: 2026-09-24

## 文脈

[0006](0006-walk-stops-at-floor-edge.md) は、床の半辺 20 に対し、歩行する主体の中心の X と Z を ±19.5 に収める。壁はなく、主体同士はすり抜ける。[0007](0007-player-and-opponent-one-loop.md) で相手は `(0, 0, 4)` にあり、動かない。

アリーナは閉じている。動いたあとに重なりを消し、壁の内側と、相手の立方体の外で止まる。落下と重力はこの決定に入れない。

## 決定

床の縁 `x, z = ±20` に、動かない壁の内面を置く。壁は見える箱である。厚みは 1、高さは 2 で、底は主体の底と同じ `Y = -0.5` である。±X の壁は角を含めて Z を外側まで覆う。±Z の壁は、内面のあいだの X だけを覆い、外へ同じ厚みだけ出る。壁の色は一色で、主体の色とは分ける。面ごとの色は付けない。

主体の半辺は 0.5 のまま。重なりは軸に沿った箱で見る。ヨーによる角のはみ出しは詰めない。

歩行が X と Z を動かしたあと、その移動を軸ごとに見る。先に X だけ動かした位置を見る。壁か、自分以外の主体に重なったら、X の移動だけ取り消す。つぎに Z で同じことをする。面へ寄せない。押し出しの連鎖や反発はしない。Y は変えない。

重ならない中心は、壁の内面から半辺だけ内側に残る。±19.5 の床端クランプは、この解消に置き換える。

歩くのはプレイヤーだけである。相手は動かない。プレイヤーが相手へ歩くと、相手の箱の手前で止まる。主体は 0007 の並びのままである。種類や基底は足さない。解消は歩行のつぎの段で、その並びを読む。

速さ、経過時間、歩行の向きは 0004 と 0005 のままである。

歩いていないフレームでは、すでに重なっている位置を押し出さない。パネルで壁や他の主体の中へ置いたとき、結果が重ならない軸の移動だけが残る。

重力、落下、剛体、速度の蓄積、斜面、段差、ナビメッシュ、攻撃、外部の物理ライブラリは含めない。この解消が手に負えなくなったときは、別の issue で選ぶ。

## 結果

- 壁が見え、その内面の手前で歩みが止まる。床端のクランプはない。
- 相手の立方体の手前で止まる。相手は初期位置から動かない。
- 斜めに当たると、重なった軸だけ止まり、もう一方の軸は進む。
