# 歩行は床の端で止まる

- 状態: `accepted`
- 日付: 2026-09-24
- 追加: 止まる対象はプレイヤーだけである。[0007](0007-player-and-opponent-one-loop.md)。範囲の決め方はここが現在の決定である。

## 文脈

[0003](0003-cube-walks-on-ground.md) の床は、`Renderer` の中の板一枚である。一辺は 40 で、歩行からは見えない。WASD は XZ をいくらでも進み、板の外でも Y は 0 のまま浮く。

落ちることは、重力と速度を持つ。それは物理の入口なので、この記録には入れない。

## 決定

歩行は、立方体の底が板の上に残る範囲で止める。板の半辺は 20、立方体の半辺は 0.5 なので、中心の X と Z は ±19.5 までである。ヨーで対角線が外にはみ出すことは、この記録では詰めない。

この範囲は、床の頂点と歩行が同じ定数を読む。床のメッシュは `Renderer` の中に置いたまま、`SceneState` には入れない。

パネルで位置を板の外へ置ける。その状態から歩くと、次の一歩で範囲の中へ戻る。

Y は変えない。速さ、経過時間の上限、カメラの周回、歩行の向きは、0004 と 0005 のままである。

重力、落下、剛体、外部の物理ライブラリ、斜面、段差は含めない。

## 結果

- 板の端は、描画と歩行で一つの半辺である。
- 歩行は床の外へ出さない。落ちる動きは、別の ADR まで入れない。
