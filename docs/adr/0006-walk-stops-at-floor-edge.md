# 歩行は床の端で止まる

- 状態: `accepted`
- 日付: 2026-09-24
- 言葉: [../words.md](../words.md)
- 置き換え: 中心を ±19.5 に収める固定は [0008](0008-walk-stops-before-wall-and-subject.md) が置き換えた。床から落ちないことは、ここがいまの判断である。

## なぜ

床は描画だけの板だった。WASD は XZ をいくらでも進み、板の外でも Y は 0 のまま浮く。落ちる動きは重力と速度を持つので、この記録には入れない。

## 決めたこと

歩行は、立方体の底が板の上に残る範囲で止める。当時の数字は、板の半辺 20、立方体の半辺 0.5、中心の X と Z は ±19.5 まで。ヨーで対角線が外にはみ出すことは、この記録では詰めない。

床の頂点と歩行は同じ半辺を読む。床のメッシュは `Renderer` の中に置いたまま、`SceneState` には入れない。

パネルで位置を板の外へ置ける。その状態から歩くと、次の一歩で範囲の中へ戻る。

## 採らない

重力。落下。剛体。外部の物理ライブラリ。斜面。段差。

## あとから

端の数字の固定は 0008 の壁の手前で止まることに置き換わった。落ちないことは、ここから変えていない。

当時は止まる対象をプレイヤーだけと書いた。誰が歩くかは、あとの ADR が広げた。ここは床の端の判断だけである。
